작성: 2026-11-01 · 수정: 2026-11-02

## 제공 방식

동네 시설은 독립 하단 메뉴와 `/[locale]/facilities` 페이지로 제공한다. 육아 소통에는 게시판·지원금·나눔장터만 남긴다. 주소 국가가 한국(`KR`)일 때만 PC·모바일에 동네 시설 메뉴를 표시한다. 한국은 하단 메뉴 7개, 해외 또는 국가 미설정은 6개이며 320px에서도 항목별 44px 이상 터치 영역을 확인한다. 해외·미설정 상태에서 시설 주소를 직접 열면 육아 소통으로 이동하고, 시설 추가 조회 API도 공공데이터 요청 전에 차단한다. 기존 `/community/map` 주소는 질의값을 보존해 새 페이지로 이동한다.

동네 시설은 지도 SDK 대신 목록과 네이버 지도·카카오맵 검색 링크를 제공한다. 동네 시설 목록은 저장 지역을 사용하며, 오늘 화면에서 나들이가 진행 중일 때만 작은 주변 정보를 위해 선택적 GPS 권한을 요청한다. 선택한 시·군·구만 공공 API에 보내며 아이·가족 ID는 보내지 않는다. 지역을 둘러봐도 가족의 저장 주소는 변경하지 않는다.

## 서버 키와 환경 분리

- 로컬 비공개 파일: `.secrets/development-public-data.env`. 일반 인증키(Decoding)를 `PUBLIC_DATA_SERVICE_KEY`에 저장한다. 파일은 Git에서 제외되며 소유자만 읽고 쓸 수 있다.
- 로컬 웹 서버는 `.env.local`의 서버 전용 `PUBLIC_DATA_SERVICE_KEY`를 읽는다. `NEXT_PUBLIC_`로 노출하지 않는다. Vercel은 develop 전용 Preview 환경의 Secret `DATA_SERVICE_KEY`로 설정한다. 서버는 이 이름을 우선 사용하고, 로컬의 `PUBLIC_DATA_SERVICE_KEY`도 호환한다. `PUBLIC_` 접두사가 붙은 공개 설정으로 등록하지 않는다.
- 어린이집 전국 목록은 `https://api.childcare.go.kr/mediate/rest/cpmsapi021/cpmsapi021/request`와 `CHILDCARE_API_KEY`, 개별 기본정보는 `cpmsapi030/cpmsapi030/request`와 별도 `CHILDCARE_DETAIL_API_KEY`로 구분한다. 목록 키를 개별 조회 API에 보내 발생한 `INFO-100`은 목록 키의 승인 실패를 의미하지 않는다. 2026-11-02 어린이집 두 키를 개발 Vercel `Preview/develop` Secret과 `.env.local`에 반영했다. `.secrets` 변경은 자동 동기화되지 않는다. 이후 운영계정용 키로 교체해 지역 기본정보의 실제 이름·주소·좌표를 확인했다. 상세 API는 `arcode` 지역 단위로도 조회할 수 있으며, 효창방과후어린이집의 일시적 HTTP 500은 재시도에서 회복됐으며 새꿈어린이집과 함께 실제 이름·주소를 확인했다. 개별 ID 조회 오류를 빈 시설 목록으로 바꾸지 않는다. 갱신 관리 기준일은 2026-11-02, 다음 갱신 예정일은 2027-11-02이며 실제 포털 종료일이 우선이다. 상세 일정과 다른 키의 만료 점검은 README를 따른다.
- 유치원은 별도 서버 비밀값 `KINDERGARTEN_API_KEY`를 사용한다. 원본 응답에 포함된 `key`와 대표자·원장 이름은 캐시·화면에서 제외하고 시설명·주소·전화·운영시간·공시 시점만 사용한다.
- 지원금 워커는 `GOV24_SERVICE_KEY`를 우선 사용하고 `PUBLIC_DATA_SERVICE_KEY`를 대체 키로 사용할 수 있다. 설정 스크립트도 같은 규칙을 사용한다.
- 운영 프로젝트에는 이번 연결을 적용하지 않는다. 운영 공개 시 별도로 키와 일정을 설정한다.

지원금 연결 명령:

```sh
node --env-file=.secrets/development-app.env --env-file=.secrets/development-public-data.env scripts/configure-parenting-support.mjs --project-ref aacmsohijybjiyidfzgy
```

지원금 수집은 전체 페이지 성공 후 트랜잭션으로 교체한다. 원문·기관·기간·대상을 보존한다. 별도 지역 공고 전체를 보장하거나 지원 대상이라고 확정하지 않는다. 조회에는 임의 300건 제한을 두지 않고, DB 제한에 맞춰 나누어 가져온다. 지역을 저장하지 않은 사용자도 전국 공통 혜택을 볼 수 있다.

## 캐시와 운영 상태

- 병원·약국: 지역 전체 목록을 500건씩 공유 캐시에 24시간 보관한 뒤 전체 시설에 거리 정렬·운영시간 필터를 적용하고 화면에 10곳씩 표시한다. 구당 20,000건을 초과하거나 수집 중 건수가 바뀌거나 중복·누락이 있으면 불완전 결과를 게시하지 않는다. 화면에 보이는 시설만 상세 조회해 요일별 시간을 보완하며 상세 결과도 24시간 공유 캐시한다.
- ‘운영 시간 내’는 게시된 시간 기준이다. 공휴일 조회 실패, 빠진 시간, 야간 경계가 불명확한 경우 ‘시간 확인 필요’로 표시한다. 실제 접수 가능·휴진 여부는 보장하지 않는다. 오늘 운영시간과 월~일·공휴일 시간을 펼쳐 볼 수 있다. 시간이 빠진 요일은 휴무로 추정하지 않는다. 오늘의 등록 시간 전이면 ‘운영 시간 전’으로 구분한다.
- 거리 기준점은 기상청 공식 XLSX의 위경도를 사용한다. 등록 법정동과 행정동 이름이 일치하지 않으면 상위 지역의 공식 좌표를 사용한다. 요청에 따라 기준 지명·가까운 순 안내와 기준점 선택 UI는 표시하지 않으며 계산과 정렬만 유지한다. 가족의 저장 주소는 바꾸지 않는다. 기저귀맵은 좌표가 검증된 시설만 거리 정렬하며 없는 시설은 뒤에 표시한다. 좌표가 없는 시설을 임의로 근처라고 배치하지 않는다. 선택한 구 안에서의 직선거리이며 도보·차량 거리나 GPS 기준 거리가 아니다.
- 선택 사항: 서버 전용 `KAKAO_REST_API_KEY`가 설정되면 공식 지역 좌표에 정확히 일치하지 않는 동 이름에 대해 카카오 주소 좌표 API를 조회한다. 동네 수준 주소만 전송하고 결과를 30일 캐시한다. 실패하면 출처가 명확한 상위 지역 좌표로 돌아간다. 시설 지도 링크에는 좌표를 사용하지 않으며 시설명 + 동 이름(없으면 구·군 이름)만 검색한다.
- 기상청: 10분 캐시. 발표가 완료된 시간대를 요청한다. 공식 격자표에서 정확히 일치하는 행정구역을 찾고 없으면 상위 지역으로 한 단계씩 올라가며, 실제 사용한 지역 이름과 관측 시각을 표시한다. 법정동을 비슷한 행정동으로 추정하지 않는다.
- 에어코리아: 시·도별 30분 캐시. 지역 이름이 일치하는 측정소를 자동 선택하고 변경 UI는 제공하지 않는다. 가장 가까운 측정소라고 추정하지 않고 측정소 이름·시각을 표시한다. 결측 `-`는 0으로 바꾸지 않는다.
- 키즈카페: `data/facilities/kids-cafes/`의 공식 원본 6개와 manifest로 서비스 목록 195곳을 생성한다. 서울 공공형 151곳을 유지하고 민간 서울 인허가 파일은 제외한다. 부산은 확보된 5개 구·군만 제공한다. 경기도는 정확한 원본 미확보로 제외한다. 원본 SHA-256과 출처별 기준일을 확인하며 구별 거리 정렬 뒤 10건씩 표시한다. 좌표가 없는 부산 시설의 거리는 생성하지 않는다. 원본의 명백한 위경도 열 뒤바뀜은 국내 좌표 범위로 검증하고 교정 수를 기록한다. 주소 약칭과 중복 표기만 정리하며 층수가 다른 시설을 임의로 합치지 않는다.
- 어린이집: 공식 지역코드로 `cpmsapi021` 목록과 `cpmsapi030` 지역 기본정보를 각각 24시간 공유 캐시한다. 목록의 ID에 맞는 기본정보만 결합한 후 지역 전체 거리 정렬과 10건 단위 페이지를 적용한다. 기본정보 실패 시 실제 목록은 유지하고, 없는 좌표를 생성하지 않는다. 원장명·인증키 등은 응답에서 제외한 후 캐시한다. XML 형식·ID·중복·예시 값·국내 좌표 범위를 검증한다.
- 각 공급자 실패는 해당 패널에서 처리한다. API URL·인증키·원본 오류 응답을 로그나 브라우저에 전달하지 않는다.

## 고정 자료의 출처

- `data/facilities/kids-cafes/sources/`: 서울 공공형 사용자 제공 JSON(2026-10-03)과 부산 기장군·해운대구·부산진구·강서구·북구 공식 CSV. 정확한 파일명·출처 URL·지역·라이선스·기준일은 같은 폴더의 `manifest.json`에 기록한다. 전체 원본과 표시용 `catalogue.json`은 Next.js 파일 추적 설정으로 Vercel 서버에 포함한다. 관리·교체 절차는 README의 키즈카페 파일 관리 항목을 따른다.

## 모바일 표시 및 탐색

- 육아 소통·동네 시설의 보이는 페이지 제목과 상단 주소 줄은 제거한다. 화면 리더용 제목은 유지한다. 모바일에서 동네 시설의 ‘다른 지역 보기’를 숨기고, PC에서는 유지한다.
- 기온·미세먼지·초미세먼지는 색상 아이콘과 수치를 세 칸으로 표시한다. 미세먼지 아이콘의 고정 색은 항목 구분용이며 오염 등급을 뜻하지 않는다. 결측값은 ‘관측 정보 없음’으로 표시한다. 카드 우측에는 등록한 시·구·동을 모두 표시하고 측정소와 관측 시각은 작은 글씨로 표시한다. 출처 문구와 측정소 변경은 제거하고, 날씨 상태 아이콘 및 미세먼지 등급을 함께 표시한다. 모바일 카드 높이는 실제 키가 있는 WebKit 검증에서 180px 이하로 확인했다.
- 병원은 소아청소년과 진료 등록 기관을 기본으로 조회하고 전체 진료과로 전환할 수 있다. 공식 API의 `QD=D002` 필터를 사용하며, 이름에 소아과가 없는 복합 진료기관도 포함한다. 진료과 선택은 운영 중 필터·지역 변경·추가 목록 조회에 유지한다. 2026-11-02 용산구 실제 조회에서 전체 329곳, 소아청소년과 62곳을 확인했다.
- 병원·약국은 주소·거리·오늘 시간·전화·지도 링크를 유지하고 간격을 줄인다. 요일별 시간과 진료과목은 펼쳐 본다. 운영시간 기준·방문 전 전화 안내 문장은 표시하지 않는다.
- 키즈카페·기저귀맵 버튼은 선택한 지역에 실제 원본 시설이 있을 때만 표시한다. 지역을 바꿨는데 기존 종류가 지원되지 않으면 병원으로 표시하고, 추가 조회 API는 해당 종류를 404로 거절한다. 기저귀맵 주소 약칭은 공식 시도 이름으로 정규화한다.
- 시설 종류·필터 변경은 GET 질의로 클라이언트 내에서 이동하고 URL을 replace한다. 체크박스는 별도 적용 버튼 없이 즉시 반영하며, 모바일에서 지역·전체 건수 오른쪽에 표시한다. 페이지 번호와 다음 시설 버튼은 없애고, 목록 하단이 가까워지면 인증된 API에서 다음 10건을 받아 기존 목록 아래에 중복 없이 추가한다. 필터 변경 시 첫 목록부터 다시 시작한다. 문서 전체를 다시 불러오거나 방문 기록을 늘리지 않는다. 시설 페이지를 다른 메뉴에서 미리 조회해 공공 API 요청을 유발하지 않는다.
- 아이 이름 메뉴의 모바일 설정 카드는 접힌 상태에서 44px 이상 터치 영역을 유지하며 전체 높이를 66px 이하로 확인했다. 열린 카드 여백과 아이 선택 카드도 줄인다.
- 확인: 아이폰 WebKit 320/390px의 실제 병원·약국·유치원·날씨·요일별 시간과 거리 표시, 단위 테스트 29개, 관련 로컬 화면 테스트 6개.

오늘 화면은 현재 선택한 아이의 나들이가 진행 중이고 위치를 허용한 경우에만 `/api/nearby` POST로 정보를 조회한다. 서버도 RLS로 해당 아이의 활성 나들이를 확인한 뒤 좌표를 처리한다. 나들이 시작·종료는 기존 활동 타이머 구조를 재사용한다. 응답은 private/no-store이며 좌표와 가족 정보는 DB·분석 이벤트에 저장하지 않는다. 일반 HTTP LAN에서는 보안 컨텍스트 제약으로 미노출한다. 서버 공공 API는 지역·기상 격자·약 1km 반올림 좌표 단위로만 공유 캐시한다.
