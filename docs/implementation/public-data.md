작성: 2026-11-01 · 수정: 2026-11-02

## 제공 방식

동네 시설은 독립 하단 메뉴와 `/[locale]/facilities` 페이지로 제공한다. 육아 소통에는 게시판·지원금·나눔장터만 남긴다. 하단 메뉴는 총 7개이며 320px에서도 항목별 44px 이상 터치 영역을 확인한다. 기존 `/community/map` 주소는 질의값을 보존해 새 페이지로 이동한다.

동네 시설은 지도 SDK 대신 목록과 네이버 지도·카카오맵 검색 링크를 제공한다. 단말 GPS를 요청하지 않는다. 선택한 시·군·구만 공공 API에 보내며 아이·가족 ID는 보내지 않는다. 지역을 둘러봐도 가족의 저장 주소는 변경하지 않는다.

## 서버 키와 환경 분리

- 로컬 비공개 파일: `.secrets/development-public-data.env`. 일반 인증키(Decoding)를 `PUBLIC_DATA_SERVICE_KEY`에 저장한다. 파일은 Git에서 제외되며 소유자만 읽고 쓸 수 있다.
- 로컬 웹 서버는 `.env.local`의 서버 전용 `PUBLIC_DATA_SERVICE_KEY`를 읽는다. `NEXT_PUBLIC_`로 노출하지 않는다. Vercel은 develop 전용 Preview 환경의 Secret `DATA_SERVICE_KEY`로 설정한다. 서버는 이 이름을 우선 사용하고, 로컬의 `PUBLIC_DATA_SERVICE_KEY`도 호환한다. `PUBLIC_` 접두사가 붙은 공개 설정으로 등록하지 않는다.
- 유치원은 별도 서버 비밀값 `KINDERGARTEN_API_KEY`를 사용한다. 원본 응답에 포함된 `key`와 대표자·원장 이름은 캐시·화면에서 제외하고 시설명·주소·전화·운영시간·공시 시점만 사용한다.
- 지원금 워커는 `GOV24_SERVICE_KEY`를 우선 사용하고 `PUBLIC_DATA_SERVICE_KEY`를 대체 키로 사용할 수 있다. 설정 스크립트도 같은 규칙을 사용한다.
- 운영 프로젝트에는 이번 연결을 적용하지 않는다. 운영 공개 시 별도로 키와 일정을 설정한다.
- `PLAYGROUND_API_KEY`가 있으면 놀이시설 요청에만 별도 키로 사용한다. 일반 인증키로 승인된 API는 별도 키가 필요 없다.

지원금 연결 명령:

```sh
node --env-file=.secrets/development-app.env --env-file=.secrets/development-public-data.env scripts/configure-parenting-support.mjs --project-ref aacmsohijybjiyidfzgy
```

지원금 수집은 전체 페이지 성공 후 트랜잭션으로 교체한다. 원문·기관·기간·대상을 보존한다. 별도 지역 공고 전체를 보장하거나 지원 대상이라고 확정하지 않는다. 조회에는 임의 300건 제한을 두지 않고, DB 제한에 맞춰 나누어 가져온다. 지역을 저장하지 않은 사용자도 전국 공통 혜택을 볼 수 있다.

## 캐시와 운영 상태

- 병원·약국: 지역 전체 목록을 500건씩 공유 캐시에 24시간 보관한 뒤 전체 시설에 거리 정렬·운영시간 필터를 적용하고 화면에 10곳씩 표시한다. 구당 20,000건을 초과하거나 수집 중 건수가 바뀌거나 중복·누락이 있으면 불완전 결과를 게시하지 않는다. 화면에 보이는 시설만 상세 조회해 요일별 시간을 보완하며 상세 결과도 24시간 공유 캐시한다.
- ‘운영 시간 내’는 게시된 시간 기준이다. 공휴일 조회 실패, 빠진 시간, 야간 경계가 불명확한 경우 ‘시간 확인 필요’로 표시한다. 실제 접수 가능·휴진 여부는 보장하지 않는다. 오늘 운영시간과 월~일·공휴일 시간을 펼쳐 볼 수 있다. 시간이 빠진 요일은 휴무로 추정하지 않는다. 오늘의 등록 시간 전이면 ‘운영 시간 전’으로 구분한다.
- 거리 기준점은 기상청 공식 XLSX의 위경도를 사용한다. 등록 법정동과 행정동 이름이 일치하지 않으면 상위 지역의 공식 좌표를 사용한다. 요청에 따라 기준 지명·가까운 순 안내와 기준점 선택 UI는 표시하지 않으며 계산과 정렬만 유지한다. 가족의 저장 주소는 바꾸지 않는다. 수유실은 요청에 따라 거리 계산 없이 CSV 목록을 유지한다. 좌표가 없는 시설을 임의로 근처라고 배치하지 않는다. 선택한 구 안에서의 직선거리이며 도보·차량 거리나 GPS 기준 거리가 아니다.
- 선택 사항: 서버 전용 `KAKAO_REST_API_KEY`가 설정되면 공식 지역 좌표에 정확히 일치하지 않는 동 이름에 대해 카카오 주소 좌표 API를 조회한다. 동네 수준 주소만 전송하고 결과를 30일 캐시한다. 실패하면 출처가 명확한 상위 지역 좌표로 돌아간다. 시설 지도 링크에는 좌표를 사용하지 않으며 시설명 + 동 이름(없으면 구·군 이름)만 검색한다.
- 기상청: 10분 캐시. 발표가 완료된 시간대를 요청한다. 공식 격자표에서 정확히 일치하는 행정구역을 찾고 없으면 상위 지역으로 한 단계씩 올라가며, 실제 사용한 지역 이름과 관측 시각을 표시한다. 법정동을 비슷한 행정동으로 추정하지 않는다.
- 에어코리아: 시·도별 30분 캐시. 측정소를 직접 고를 수 있다. 가장 가까운 측정소라고 추정하지 않고 측정소 이름·시각을 표시한다. 결측 `-`는 0으로 바꾸지 않는다.
- 놀이시설: 공식 API에 주소 필터가 없어 전국 페이지를 공유 캐시(24시간)에 보관한 뒤 시·군·구별 결과를 캐시한다. 최초 조회는 페이지 수에 비례해 느릴 수 있다. 페이지 수·건수 변경이나 불완전 수집 시 결과를 게시하지 않는다. 공개 API의 사유 시설이 누구나 방문 가능한 시설이라는 뜻은 아니다.
- 각 공급자 실패는 해당 패널에서 처리한다. API URL·인증키·원본 오류 응답을 로그나 브라우저에 전달하지 않는다.

## 고정 자료의 출처

- `src/features/community/data/nursing-rooms.json`: 사용자가 제공한 `서울교통공사_수유실현황_20250924.csv`, CP949. 원본 SHA-256과 기준일을 보존한다. 상세 위치·운임 구역·기저귀 교환대 여부를 추출하며 좌표·전화·시간은 만들지 않는다.
- `src/features/community/data/kindergarten-regions.json`: 유치원알리미 `openApi/sidoSigunguCode.do` 공식 코드표. 261개 시·군·구 코드. 2026-11-01 다운로드. 확장자가 XLS 형태인 HTML 표에서 이름과 시도·시군구 코드만 추출했다.
- `src/features/community/data/area-points.json`: 같은 기상청 XLSX의 지역별 위경도 3,837개. 유효한 한국 범위 좌표만 추출했으며 가족의 개인 좌표가 아니다.
- `src/features/community/data/weather-grids.json`: 위 기상청 공식 데이터 페이지의 `기상청41_단기예보 조회서비스_오픈API활용가이드_2610.zip`에 포함된 격자·위경도 XLSX(2610). 3,838개 지역의 격자 X/Y만 추출했다. 2026-11-01 다운로드. 행정동 코드와 가족의 법정동 코드를 임의로 동일시하지 않는다.

## 검증

- `tests/unit/public-data.test.ts`: 응답 코드, 한국 시각, 공휴일·결측·야간 시간, 지도 URL 인코딩, 수유실 기준일.
- `tests/unit/public-data-server.test.ts`: API 요청의 지역·페이지, 인증키 오류 비노출, 공급자 실패 분리, 자정 전후 날씨 시각, 미세먼지 결측, 놀이시설 전국 페이지 완료 조건.
- iPhone WebKit에서 실제 개발 데이터로 병원·약국 10개 목록, 날씨, 수유실·교환대 필터, 지원금, 가로 넘침과 HTML의 키 비노출 확인. 임시 계정과 가족은 확인 후 삭제한다.

## 모바일 표시 및 탐색

- 육아 소통·동네 시설의 보이는 페이지 제목과 상단 주소 줄은 제거한다. 화면 리더용 제목은 유지한다. 모바일에서 동네 시설의 ‘다른 지역 보기’를 숨기고, PC에서는 유지한다.
- 기온·미세먼지·초미세먼지는 색상 아이콘과 수치를 세 칸으로 표시한다. 미세먼지 아이콘의 고정 색은 항목 구분용이며 오염 등급을 뜻하지 않는다. 결측값은 ‘관측 정보 없음’으로 표시한다. 카드 우측에는 등록한 시·구·동을 모두 표시하고 실제 관측 기준 지역은 하단 출처와 구분한다. 모바일 카드 높이는 실제 키가 있는 WebKit 검증에서 180px 이하로 확인했다.
- 병원·약국은 주소·거리·오늘 시간·전화·지도 링크를 유지하고 간격을 줄인다. 요일별 시간과 진료과목은 펼쳐 본다. 운영시간 기준·방문 전 전화 안내 문장은 표시하지 않는다.
- 시설 종류·필터·페이지 변경은 클릭한 버튼 값까지 포함한 GET 질의로 클라이언트 내에서 이동하고 URL을 replace한다. 문서 전체를 다시 불러오거나 방문 기록을 늘리지 않는다. 시설 페이지를 다른 메뉴에서 미리 조회해 공공 API 요청을 유발하지 않는다.
- 아이 이름 메뉴의 모바일 설정 카드는 접힌 상태에서 44px 이상 터치 영역을 유지하며 전체 높이를 66px 이하로 확인했다. 열린 카드 여백과 아이 선택 카드도 줄인다.
- 확인: 아이폰 WebKit 320/390px의 실제 병원·약국·유치원·날씨·요일별 시간과 거리 표시, 단위 테스트 25개, 관련 로컬 화면 테스트 6개.
