## 제공 방식

주변 시설은 지도 SDK 대신 목록과 네이버 지도·카카오맵 검색 링크를 제공한다. 단말 GPS를 요청하지 않는다. 선택한 시·군·구만 공공 API에 보내며 아이·가족 ID는 보내지 않는다. 지역을 둘러봐도 가족의 저장 주소는 변경하지 않는다.

## 서버 키와 환경 분리

- 로컬 비공개 파일: `.secrets/development-public-data.env`. 일반 인증키(Decoding)를 `PUBLIC_DATA_SERVICE_KEY`에 저장한다. 파일은 Git에서 제외되며 소유자만 읽고 쓸 수 있다.
- 로컬 웹 서버는 `.env.local`의 서버 전용 `PUBLIC_DATA_SERVICE_KEY`를 읽는다. `NEXT_PUBLIC_`로 노출하지 않는다. Vercel은 develop 전용 Preview 환경의 Secret `DATA_SERVICE_KEY`로 설정한다. 서버는 이 이름을 우선 사용하고, 로컬의 `PUBLIC_DATA_SERVICE_KEY`도 호환한다. `PUBLIC_` 접두사가 붙은 공개 설정으로 등록하지 않는다.
- 유치원은 별도 서버 비밀값 `KINDERGARTEN_API_KEY`를 사용한다. 원본 응답에 포함된 `key`와 대표자·원장 이름은 캐시·화면에서 제외하고 시설명·주소·전화·운영시간·공시 시점만 사용한다.
- 지원금 워커는 `GOV24_SERVICE_KEY`를 우선 사용하고 `PUBLIC_DATA_SERVICE_KEY`를 대체 키로 사용할 수 있다. 설정 스크립트도 같은 규칙을 사용한다.
- 운영 프로젝트에는 이번 연결을 적용하지 않는다. 운영 공개 시 별도로 키와 일정을 설정한다.
- `PLAYGROUND_API_KEY`가 있으면 놀이시설 요청에만 별도 키로 사용한다. 일반 인증키로 승인된 API는 별도 키가 필요 없다.

지원금 연결 명령:

```sh
node --env-file=.secrets/development-app.env --env-file=.secrets/development-public-data.env scripts/configure-parenting-support.mjs --project-ref aacmsohijybjiyidfzgy
```

지원금 수집은 전체 페이지 성공 후 트랜잭션으로 교체한다. 원문·기관·기간·대상을 보존한다. 별도 지역 공고 전체를 보장하거나 지원 대상이라고 확정하지 않는다. 조회에는 임의 300건 제한을 두지 않고, DB 제한에 맞춰 나누어 가져온다. 지역을 저장하지 않은 사용자도 전국 공통 혜택을 볼 수 있다.

## 캐시와 운영 상태

- 병원·약국: 지역·페이지별 목록과 시설별 상세를 24시간 캐시한다. 일요일·공휴일에만 누락된 특별 운영시간을 상세 API로 보완한다. 한번에 10개씩 조회한다.
- ‘운영 시간 내’는 게시된 시간 기준이다. 공휴일 조회 실패, 빠진 시간, 야간 경계가 불명확한 경우 ‘시간 확인 필요’로 표시한다. 실제 접수 가능·휴진 여부는 보장하지 않는다. 운영시간 필터는 현재 페이지에 적용됨을 표시한다.
- 기상청: 10분 캐시. 발표가 완료된 시간대를 요청한다. 공식 격자표에서 정확히 일치하는 행정구역을 찾고 없으면 상위 지역으로 한 단계씩 올라가며, 실제 사용한 지역 이름과 관측 시각을 표시한다. 법정동을 비슷한 행정동으로 추정하지 않는다.
- 에어코리아: 시·도별 30분 캐시. 측정소를 직접 고를 수 있다. 가장 가까운 측정소라고 추정하지 않고 측정소 이름·시각을 표시한다. 결측 `-`는 0으로 바꾸지 않는다.
- 놀이시설: 공식 API에 주소 필터가 없어 전국 페이지를 공유 캐시(24시간)에 보관한 뒤 시·군·구별 결과를 캐시한다. 최초 조회는 페이지 수에 비례해 느릴 수 있다. 페이지 수·건수 변경이나 불완전 수집 시 결과를 게시하지 않는다. 공개 API의 사유 시설이 누구나 방문 가능한 시설이라는 뜻은 아니다.
- 각 공급자 실패는 해당 패널에서 처리한다. API URL·인증키·원본 오류 응답을 로그나 브라우저에 전달하지 않는다.

## 고정 자료의 출처

- `src/features/community/data/nursing-rooms.json`: 사용자가 제공한 `서울교통공사_수유실현황_20250924.csv`, CP949. 원본 SHA-256과 기준일을 보존한다. 상세 위치·운임 구역·기저귀 교환대 여부를 추출하며 좌표·전화·시간은 만들지 않는다.
- `src/features/community/data/kindergarten-regions.json`: 유치원알리미 `openApi/sidoSigunguCode.do` 공식 코드표. 261개 시·군·구 코드. 2026-11-01 다운로드. 확장자가 XLS 형태인 HTML 표에서 이름과 시도·시군구 코드만 추출했다.
- `src/features/community/data/weather-grids.json`: 위 기상청 공식 데이터 페이지의 `기상청41_단기예보 조회서비스_오픈API활용가이드_2610.zip`에 포함된 격자·위경도 XLSX(2610). 3,838개 지역의 격자 X/Y만 추출했다. 2026-11-01 다운로드. 행정동 코드와 가족의 법정동 코드를 임의로 동일시하지 않는다.
