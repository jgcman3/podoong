# 놀이터 인사·하트 웹 푸시

수정일: 2026-11-04

## 설정과 첫 안내

아이 이름 메뉴의 알림 설정에서 식사 알림과 별도로 인사·하트 알림을 켜고 끈다. 기본값은 끄기이며 기기 권한을 자동 요청하지 않는다. 식사 알림을 꺼도 놀이터만 켤 수 있다. 설정은 보호자 계정별이며 기기 등록은 기존 웹 푸시 구독을 공유한다. 이 기기 알림 끄기와 로그아웃은 이 기기의 구독을 삭제해 두 종류 모두 중지한다.

놀이터의 야간 쉬기는 식사의 야간 설정과 별개이고 계정 시간대 22:00–07:00에 적용한다. 가입 후 설치 화면은 알림 종류, 선택 설정, 기기별 가이드와 알림 설정 링크를 제공한다. 아이폰·아이패드는 iOS 16.4 이상에서 홈 화면 설치 후 실행해야 하며, Android/PC는 지원 브라우저·HTTPS·사용자 권한 허용이 필요하다. 실제 표시 여부는 운영체제·집중 모드·브라우저에 영향을 받는다.

## 발송 구조

마이그레이션 096은 `notification_preferences`의 놀이터 선택값, `playground_push_deliveries`, 큐 트리거와 서비스 역할 전용 발송 RPC를 추가한다. 새로운 인사·하트만 동일 기기/아이/2분 구간당 한 건으로 모은다. 일일 중복 인사는 기존 반응 저장 제약으로 추가 발송을 만들지 않는다. 위로 반응은 기존 이력에만 남는다. 구독·옵트인 이전의 반응은 재발송하지 않는다.

기존 `podung-feeding-push` Cron과 `feeding-push` Edge Function, Vault 작업자 토큰, VAPID 키를 재사용한다. 추가 인증키나 예약 작업은 필요 없다. 함수는 식사/놀이터 두 큐를 처리하며 각 배치의 HTTP 요청 동시성은 최대 5개다. 신규 큐는 호출당 최대 10건을 3분 임대로 가져오며 실패는 최대 3회 재시도한다. 허용된 브라우저 푸시 서버만 호출하고 404/410 구독은 삭제한다.

발송 직전에 알림 선택, 구독, 아이 읽기 권한, 송·수신 아이의 놀이터 동의, 현재 동네·날짜, 야간·일시정지·탈퇴 대기를 검사한다. 야간이나 유효시간이 지난 반응을 다음 날 밀어 보내지 않는다. 예정 시각에서 10분이 지나면 취소한다. 공급자 전송 TTL은 5분이며 네트워크 응답 소실에 따른 중복 가능성은 아이별 고정 알림 태그로 완화한다.

잠금화면에는 인사·하트 개수만 표시하며 가족·아이 이름과 사진을 넣지 않는다. 알림을 누르면 같은 출처의 `/{locale}/community/playground?child=...&inbox=1`을 열고 받은 이력을 바로 보여준다. 기존 창이 있으면 재사용한다. 서비스 워커는 페이지/아이 기록을 캐시하지 않으며 오늘/놀이터 경로만 허용한다.

발송 메타데이터는 기존 Cron에서 최대 2일 후 정리하고 구독·아이 삭제 시 즉시 연계 삭제한다. 수신 이력은 기존 정책대로 당일만 표시한다. 개인정보 처리방침은 이 선택적 알림과 보유기간을 반영하며 기존 가입 동의 원문 스냅샷은 수정하지 않는다.

## 반영과 검증

앱·096 DB 변경과 `feeding-push` 함수 코드를 함께 반영해야 한다. 개발·운영은 각 프로젝트별로 적용하고 기존 환경의 VAPID 키를 재생성하지 않는다. 실제 단말 수신 검증은 해당 기기에서 동의한 테스트 구독으로만 진행한다. SQL/단위/브라우저 테스트 대역은 실제 잠금화면 수신 성공을 증명하지 않는다.
