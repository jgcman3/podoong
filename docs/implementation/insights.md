# 주간 인사이트

갱신: 2026-10-26

## 이용 흐름

하단·사이드 메뉴와 전체 서비스에 ‘인사이트’를 제공합니다. 오늘을 포함한 최근 7일이 기본이며 이전·다음 버튼은 7일씩 이동합니다. 월요일~일요일로 맞추지 않으며 지정한 시작 날짜를 유지합니다. 미래 기간은 최근 7일로 제한합니다.

16개 기능을 여러 개 선택·해제할 수 있습니다. 주간 패턴은 시간 눈금을 왼쪽에만 두고 날짜만 표시하며, 기능 수와 관계없이 날짜 칸 전체 너비의 고정 두께 가로 선으로 기록 시각을 표시합니다. 원본 시각의 분·초를 사용하므로 같은 시간대의 서로 다른 기록을 한 시간으로 뭉치지 않습니다. 수면은 날짜별 실제 구간을 옅은 배경과 시작 선으로 표시합니다. 시각 없는 접종 기록은 별도로 표시합니다.

패턴 영역을 오른쪽으로 드래그하면 이전 7일, 왼쪽으로 드래그하면 다음 7일로 이동합니다. 휴대폰의 세로 스크롤·확대 동작은 유지하고 키보드 좌우 화살표도 지원합니다. 최신 기간보다 미래로 이동하지 않습니다.

보기 탭은 ‘하루 패턴 · 주간 패턴 · 통계 정보’ 순서입니다. 통계 정보에서만 핵심 수치·선그래프를 표시하며 패턴 화면에는 반복 노출하지 않습니다. 하루·주간 패턴의 기간 선택은 탭 바로 아래에 왼쪽 화살표·가운데 날짜·오른쪽 화살표로 통일합니다. 통계 정보에는 날짜 범위·이전/다음 이동을 표시하지 않고 ‘일단위 (일주일기간) · 주단위 (6주기간)’ 선택만 제공합니다.

‘하루 패턴’은 24시간 원형 시계이며 날짜 버튼·좌우 드래그로 하루씩 이동합니다. 가운데에는 `D+일수`만 표시하며 ‘생후’ 문구는 두지 않습니다. 시각만 있는 기록은 고정 크기 눈금이며 실제 활동 기간으로 해석하지 않습니다. 수면은 실제 시작·종료 구간을 원형 띠에 표시합니다. 하루가 현재 7일 범위를 벗어나면 해당 기간을 조회합니다. 보기 방식·날짜·기능은 아이·언어 전환에도 유지됩니다. 패턴의 실제 시각은 펼침 표에서 확인합니다.

화면의 반복 제목은 표시하지 않습니다. 기능 선택 목록은 PC에서 본문 상단에, 760px 이하 휴대폰 화면에서 하단 메뉴 바로 위에 고정합니다. 기능 목록은 마우스·터치 좌우 드래그로 스크롤하며, 드래그를 선택 클릭으로 처리하지 않습니다. 세로 스크롤·확대·키보드 선택은 유지합니다. 하단 목록은 가로 스크롤로 선택하며 본문에는 목록 높이와 안전 영역만큼 여백을 확보합니다.

기능 선택과 보기·날짜 이동은 같은 내비게이션 상태를 사용하고, 모든 이동 요청에 현재 선택한 기능 전체를 명시합니다. 선택을 연달아 바꾸어도 마지막 선택을 기준으로 요청합니다.

통계는 ‘일 단위’에서 7개 날짜, ‘주 단위’에서 6개 주간 합계를 선그래프로 표시합니다. 각 주는 월요일에 맞추지 않고 선택한 7일 블록을 기준으로 이전 5주와 이어집니다. 그래프 날짜 눈금과 표에는 해당 집계 날짜를 유지합니다. 기록이 없는 구간은 빈 값으로 남기며 0이나 연속된 선으로 만들지 않습니다. 모든 그래프는 값 선택과 표 조회를 지원합니다.

| 기능                                          | 핵심 통계                                                                                        |
| --------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 분유·이유식                                   | 선택 기능의 전체 ml와 기능별 ml를 하나의 그래프에 표시                                           |
| 모유                                          | 단독 선택 시 수유 시간 그래프; 분유·이유식과 함께 선택하면 시간만 별도 표시하고 ml 합계에서 제외 |
| 수면                                          | 실제 수면 총시간(시간)                                                                           |
| 기저귀·배변·목욕·병원·예방접종·투약·간식·발달 | 하나의 횟수 그래프에 기능별 선과 각 합계 표시                                                    |
| 체온                                          | 전체 측정값 평균                                                                                 |
| 놀이·터미타임                                 | 총시간(분)                                                                                       |
| 성장                                          | 몸무게(kg)·키(cm) 각각 마지막 측정값 그래프                                                      |

횟수 그래프는 기저귀·배변처럼 겹치는 기록도 있으므로 전체 합계로 더하지 않고 각 기능의 합계를 따로 표시합니다.

제품 화면에는 합산·진행 중 제외·미입력 제외 같은 설명 문구를 두지 않습니다. 모유 수유 시간처럼 실제 수치는 유지합니다.

불필요한 지표 탭·기록일 평균·기록일 수·이전 기간 증감 카드는 제거합니다. 기존 g 이유식 자료는 보존하지만 ml 그래프에 합산하거나 환산하지 않습니다. 전체 해제 시 기능 선택 안내만 표시합니다. 단위·아이·언어·기간 전환에도 기능 선택을 유지합니다.

## 집계와 권한

기존 PostgreSQL 기록과 RLS를 재사용하며 새 스키마나 별도 통계 원본은 만들지 않습니다. 선택 아이의 표시 기간(7일 또는 42일) 자료를 날짜 조건 적용 후 500건씩 모두 조회합니다. 명시한 아이에 접근할 수 없으면 404이며 조회 전용 가족도 허용된 아이의 통계를 볼 수 있습니다.

- 시작일부터 7일, 보호자 설정 시간대 기준입니다. 먹인 양·횟수는 시작 날짜로 분류하며 진행 중·미래 기록은 제외합니다.
- 미입력 측정값은 0과 구분합니다. 직접 모유를 ml로 환산하지 않고 g/ml도 혼합하지 않습니다. 체온은 전체 측정값의 가중 없는 표본 평균, 성장은 날짜별 마지막 실제 측정값입니다.
- 자정을 넘은 완료 수면은 날짜·시간대에 실제 경과 분을 나눕니다. 서머타임의 반복 시간도 실제 경과량으로 처리하며 겹치는 수면 구간은 합쳐 중복 합산하지 않습니다.
- 일별 수치 집계는 기존 규칙을 유지하며, 패턴 선은 분 단위 시각과 수면 구간을 사용합니다. 접종은 실제 접종일만 사용하고 시각을 만들어 넣지 않습니다.
- 기록이 없는 날짜는 그래프에 비워 둡니다. 기록 누락을 활동 부재나 건강 판단으로 해석하지 않습니다.

## AI 브리핑 보류

최신 요청에 따라 AI 브리핑 화면·예시·서버 액션·OpenAI 호출 코드를 제거했습니다. API 키 설정 없이 인사이트를 이용하며 외부 AI 서비스로 기록을 전송하지 않습니다. 이전 로드맵의 브리핑 제공 내용은 현재 동작에 적용하지 않습니다.

## 검증

단위 테스트는 7일 기간·복수 선택·전체 해제·시간대·자정·서머타임·중복·진행 중·누락값·단위·표본 평균·최신 측정값·6주 집계·먹이기 통합 총량·모유 시간 분리를 확인합니다. 브라우저에서는 100건을 넘는 기록, 기능 동시 선택·해제와 패턴 레이어, 월요일이 아닌 시작일, 7일 이동, 고정 선 크기, 마우스·터치 드래그, 요일 제거, 하루 원형 패턴과 날짜 경계 이동, PC/모바일 표시, 아이·언어 유지, 조회 전용·아이별 권한 및 브리핑 제거를 확인합니다.

## 육아·발달 정보 (2026-10-27)

- 인사이트의 네 번째 탭 `육아·발달`에서 생후 0–60개월 정보를 제공합니다. 처음에는 선택한 아이의 출생일로 계산한 만 개월 수를 사용하며, 좌우 버튼으로 다른 월령을 볼 수 있습니다. 월말·윤년 출생일은 해당 월의 마지막 날을 기준으로 계산합니다.
- 출생 전이거나 출생일이 없으면 0개월 안내와 출생일 등록 안내를 표시합니다. 60개월을 넘으면 제공 범위를 명시하고 60개월 정보를 보여줍니다.
- 발달, 함께 하는 놀이, 먹이기, 수면, 성장 기준, 예방접종 카드를 모바일 한 열 / PC 두 열로 배치합니다. 발달 이정표의 기준 월령은 선택 월령과 별도로 표시합니다. 평균 체중·키를 임의로 생성하지 않고 WHO 원문 기준으로 연결합니다.
- 정보 탭에는 기능 선택 목록을 표시하지 않으며 돌봄 기록 통계 조회도 하지 않습니다. 다른 세 탭은 기존 모바일 하단 기능 선택 목록과 다중 선택값을 유지합니다. 기능을 모두 해제해도 탭 이동은 가능합니다.
- 일반 참고용 편집 콘텐츠이며 개인별 진단·처방·발달 판정이나 AI 생성 문구가 아닙니다. 아이별 접종 내역은 기존 예방접종 화면으로 연결하며, 접종 유무를 월령만으로 판단하지 않습니다.

## 성장곡선과 마일스톤 (2026-10-27)

### 성장곡선

- `pattern=curve`: 몸무게·키·머리둘레를 D+ 기준으로 표시합니다. 기존 가족 전용 `child_records`의 성장 수치를 읽으며 공개 일기를 조회하지 않습니다. 기록 당시 시간대의 날짜로 일령을 계산하고 출생 전·미래 기록은 제외합니다.
- WHO Child Growth Standards의 성별·일령별 LMS 원본을 사용합니다. 표시 범위는 D+0–1826이며 0–1세/0–2세/0–5세를 선택합니다. 3·10·25·50·75·90·97백분위 곡선, 실제 기록선, 선택한 기록의 수치·백분위를 표시합니다. 범위 밖 기록은 표에서 확인할 수 있지만 백분위를 외삽하지 않습니다.
- 비교 기준 성별은 아이의 등록 성별로 시작합니다. 성별 미등록 시 기준 곡선은 숨기고 선택을 안내합니다. 화면에서 바꾸는 비교 성별은 아이 프로필을 변경하지 않습니다.
- 키는 2세 전 누운 키 / 이후 선 키 기준입니다. 원본의 D+731 전환에서 곡선을 분리하며 측정 자세 보정이나 미숙아 교정 연령을 임의 적용하지 않습니다. 기록이 기준 측정 자세를 따랐다는 가정을 화면에 안내합니다.
- `scripts/import-who-growth.py`로 WHO 원본 6개를 가져와 연속 일령과 LMS 양수를 검증합니다. `reference/who-lms.json`은 일령을 배열 인덱스로 하는 `[L,M,S]` 값입니다. `reference/sources.json`에 원문 링크, 확인일, 원본 SHA-256을 기록합니다. 온라인 조회 없이 정적 기준표를 사용하며 한국 성장도표로 표시하지 않습니다.
- 백분위는 LMS z-score와 표준정규분포 CDF로 계산합니다. 경계는 `<0.1` / `>99.9`로 표시하며 정상·이상 판정을 하지 않습니다. 원문 표의 출생 시 수치, 여러 일령의 백분위 역변환, 로그 LMS 분기, 시간대 경계를 테스트합니다.

### 마일스톤

- `pattern=milestones`: CDC 기준 2·4·6·9·12·18·24·36·48·60개월의 **주요 항목**을 움직임·언어·인지·사회성으로 분류합니다. 전체 공식 검사표를 재현하거나 발달 지연을 진단하는 기능이 아닙니다. 해당 월령의 CDC 전체 체크리스트와 육아·발달 안내를 연결합니다.
- 체크 여부는 `child_milestones`에 아이/고정 항목 키별로 저장합니다. 반복 체크는 최초 관찰 기록 시각을 유지하고 체크 해제는 해당 관찰을 삭제합니다. 시각은 실제 달성일이 아닌 앱에 체크한 시각입니다.
- 마이그레이션 `202610270026_child_milestones.sql`: RLS로 가족별 읽기 권한을 검사합니다. 직접 쓰기는 차단하고 RPC에서 활성 계정·아이별 편집 권한·항목 허용 목록을 검사합니다. 아이 삭제는 cascade, 작성 계정 삭제는 기록자만 null로 처리하며 다른 가족에게 속한 아이 기록을 삭제하지 않습니다.
- 데이터 내보내기 형식 4에 `milestones`를 추가합니다. 기존 필드를 유지하고 기록한 가족의 사용자 ID는 내보내지 않습니다.
- 성장곡선·마일스톤·육아발달은 기능 선택 목록을 숨깁니다. 모바일에서도 하위 탭 없이 6개 화면을 한 줄 탭으로 바로 선택합니다.
