# 동네 소통: 놀이터·동네 이야기

수정: 2026-11-06

## 구성과 접근 범위

- 상단 탭은 **동네 놀이터 / 동네 이야기** 두 개이며, 기본 진입은 놀이터입니다. 전국 커뮤니티와 `/community/boards`는 제거했습니다.
- 거주지역이 없으면 지역 등록을 먼저 안내합니다. 국가·시군구·동(해외는 주/도·도시·동네)이 일치하는 가족끼리 이용합니다. 다른 지역을 대신 선택해 글을 쓸 수 없습니다.
- 동네 이야기 카테고리는 동네일상 / 동네나들이 / 생활정보 / 질문·도움 / 어린이집·유치원 / 중고나눔·거래 / 기타입니다. 카테고리와 전체·인기 선택은 다른 메뉴에 다녀와도 유지합니다. 선택한 카테고리를 다시 눌러 해제할 수 있습니다.
- 목록 검색은 제목·본문을 대상으로 합니다. 인기는 최근 7일의 공감·댓글 참여·조회수로 계산합니다.
- 동네마다 운영자 환영글에 해당 동네 이름을 표시합니다. 별도 지역별 게시글을 복제하지 않습니다.

## 가상 놀이터

- 같은 동네에서 그날 입장한 만 7세 미만 아이를 2.5D 사이드뷰에 배치합니다. 실제 위치·사진·다른 가족의 내부 식별자를 노출하지 않습니다.
- 현지 날짜의 첫 방문에만 기존 아이 근처 빈 위치를 지정하고 당일 위치를 유지합니다. 사전 인원 집계·자정 배치·WebSocket·게임 엔진은 없습니다.
- 스와이프·마우스 드래그로 둘러보며 우리 아이로 돌아가기 아이콘을 제공합니다. 화면 주변 구간만 최대 150명 조회하고, 보이는 동안 1분마다 상태와 출석을 갱신합니다.
- 아이 애칭과 가족 이름을 분리해 표시합니다. D+365 이전은 D+일수, 이후는 출생 연도 기준 나이를 표시합니다. 한 줄 상태는 아기 위 말풍선이며 선택한 아이를 확대합니다.
- 인사·하트·토닥토닥은 아이 쌍/종류마다 현지 날짜 기준 하루 한 번입니다. 받은 이력은 오늘 것만 보여주며 오래된 자료는 이후 요청에서 제한된 수량으로 정리합니다.
- 놀이터 알림을 켜고 기기 권한을 허용하면 받은 마음을 2분 단위로 묶어 푸시합니다. 실제 위치 공유나 별도 일정 알림은 없습니다.

## 게시글·사진·댓글

- 목록은 제목·본문 요약·썸네일·지역·시각·반응 수를 간결하게 보여주며 우측 하단 글쓰기 버튼을 제공합니다. 상세는 `/community/posts/[id]` 전체 페이지입니다.
- 제목·본문·카테고리와 최대 9장 사진, 선택적 투표를 등록합니다. `#태그`는 본문에 직접 입력합니다.
- 사진은 기기에서 긴 변 2048px·장당 350KiB 이하 JPEG로 최적화합니다. 직접 읽지 못하는 HEIC/HEIF만 추가 디코더를 불러옵니다. 한 장씩 처리해 메모리를 제한하고 처리 중 등록을 막습니다.
- 서버는 비공개 `community-photos` 버킷에 1600px·480px WebP를 저장합니다. 로그인과 동네 열람 권한을 검사한 뒤 전달하고, 삭제된 파일은 기존 사진 정리 큐로 처리합니다.
- 상세·댓글의 작성자는 가족 이름·가족 관계로 표시합니다. 목록에는 작성자 이름을 표시하지 않습니다. 댓글·답글·좋아요·투표는 권한을 확인하는 RPC로 처리하며 원본 테이블 직접 쓰기는 막습니다.
- 공유 시트에는 링크 복사와 다른 앱에 공유를 제공합니다. 공유된 링크도 로그인·같은 동네 권한이 있어야 열립니다.
- 본인 글은 편집·삭제할 수 있습니다. 타인 글의 신고는 `/admin/reports`에서 당시 본문·사유 확인과 숨김·복구·처리 완료를 지원합니다. 신고자 정보는 작성자에게 노출하지 않습니다.

## DB와 검증

- `202611060102_retire_calendar_country_community.sql`은 전국 게시글·구 게시판·동네 알리기 테이블과 해당 메타데이터를 제거합니다. 동네 이야기·공유 사진 처리·놀이터·공개 성장일기의 권한은 유지합니다.
- `supabase/tests/feature_retirement.test.sql`은 제거한 테이블·컬럼·오버로드가 없음을 검사합니다. 동네 게시글·사진·검색·댓글·신고와 놀이터 SQL 검사는 현행 기능을 검증합니다.
- `tests/e2e/app.spec.ts`에서 모바일/PC 탭, 지역 등록, 글·사진 작성, 검색·카테고리, 신고와 놀이터를 확인합니다.

## 로컬 예시

`npm run seed:playground`는 로컬 DB에만 예시 가족·아기 8명을 준비합니다. `npm run dev:playground`는 3190 포트와 전용 빌드 폴더를 사용하며 기존 개발 서버와 원격 DB는 변경하지 않습니다. 예시 계정 정보는 Git 제외 `.secrets/local-playground-demo.json`에 저장합니다.
