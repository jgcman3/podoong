# D 단계: 예방접종·독감

2026-10-14 사용자 요청으로 공식 안내와 아이별 예정·완료 기록을 구현했습니다.

## 이용 흐름

전체 서비스 → 예방접종·독감에서 **접종 예정 / 접종 완료 / 공식 안내**를 선택합니다. 목록에서 **접종 기록하기**를 누르면 별도 작성 화면으로 이동하고, 상세 화면에서 수정·삭제합니다. 완료된 접종을 새로 등록하거나 예정 기록을 수정해 완료로 바꿀 수 있습니다.

백신 종류, 차수(모르면 미입력), 예정일, 실제 접종일, 병원·접종 기관, 메모를 저장합니다. 기타·혼합백신은 이름을 직접 입력합니다. 독감 기록은 `2026-2027` 같은 절기를 선택적으로 저장합니다. 완료 기록의 실제 접종일은 미래 날짜를 허용하지 않습니다.

오늘과 일정 화면에 해당 아이의 예정 접종 최대 3건을 표시합니다. 다가오는 일정과 같은 카드 스타일로 월·일 날짜 블록, 접종명, 남은 날짜, 차수·절기·병원 정보를 표시하며 제목을 누르면 상세 기록으로 이동합니다. 예정일이 지나면 표시하고 기록을 유지합니다. 완료로 변경하거나 삭제하면 예정 목록에서도 반영됩니다. 예약 대행이나 알림 전송은 제공하지 않습니다.

## 공식 안내

한국어·영어 안내에 출처와 확인일(2026-10-14)을 표시합니다. 한국 기준의 일반 안내이며 개인별 접종 날짜·횟수를 자동 결정하지 않습니다. 제품과 이전 접종 이력을 의료기관에서 확인한 뒤 기록합니다. 공식 접종 이력은 질병관리청에서 별도로 확인하며 포둥 기록과 자동 연동하지 않습니다.

- [질병관리청 표준 예방접종 일정표](https://nip.kdca.go.kr/irhp/infm/goVcntInfo.do?menuCd=115&menuLv=1)
- [질병관리청 인플루엔자 안내](https://nip.kdca.go.kr/irhp/infm/goVcntInfo.do?menuCd=1112&menuLv=1)
- [독감 위탁의료기관 찾기](https://nip.kdca.go.kr/irhp/mngm/goVcntMngm.do?menuCd=333)

절기별 지원 연령·기간은 변경될 수 있어 고정된 지원 대상이나 개인별 2차 접종일을 생성하지 않습니다. 공식 자료 변경 시 안내 문구·번역·확인일을 함께 검토합니다.

## 데이터와 권한

마이그레이션 `202610140013_vaccination.sql`은 PostgreSQL의 `vaccination_records`와 저장·삭제 RPC, 아이 접근 권한 RLS를 추가합니다. 가족 편집자는 관리하고 조회 전용 보호자는 읽기만 가능합니다. RPC는 입력 검증·수정 버전 검사·감사 로그를 적용하며 다른 아이로 기록을 옮길 수 없습니다.

내보내기 형식 3의 `vaccinations`에 모든 접종 기록을 포함하고 작성자 식별자를 제거합니다. 아이 삭제는 기록을 함께 삭제하며, 계정 삭제는 남은 가족 기록을 보존하면서 작성자를 익명화합니다. 백업 복원 검증에도 새 테이블을 포함합니다.

2026-10-14 연결된 `mkybqrhjrpouxmxizmpt` 프로젝트에 `013`을 적용했습니다. 원격 사용자 자료를 수정하거나 테스트 계정을 생성하지 않았습니다. 모든 테스트 자료는 로컬 DB에서 생성·정리합니다. 실제 가족 파일럿과 공개 출시 전 건강 안내·번역 검수는 별도 운영 항목입니다.
