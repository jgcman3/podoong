# 나들이 주변 정보

수정일: 2026-11-02

## 범위

오늘 메뉴에서 나들이를 시작하고 위치를 허용한 경우에만 날씨·기온·미세먼지, 현재 운영 중인 소아청소년과 등록 병원·약국, 가까운 기저귀 교환 장소를 작게 표시한다. 동네 시설 메뉴와 지역별 시설 탐색은 제거했다. 육아 소통의 게시판·지역 필터·지원금·장터는 유지한다.

## 코드·데이터

- `src/features/outing/`: 시작 클릭의 위치 요청, 주변 정보 UI, 공식 API, 거리·운영시간 계산, 날씨·미세먼지 처리.
- `src/features/care/`: 기존 나들이 활동 타이머·시작/종료 기록.
- `/api/nearby`: 로그인·동일 출처·선택한 아이의 활성 나들이를 RLS로 확인한 뒤 조회. 좌표는 POST 본문으로만 수신하며 응답은 private/no-store.
- `data/outing/diaper-map/`: 공중화장실 원본과 UTF-8 변환 gzip, 공식 표준 좌표 대조 원본, 해시·출처 manifest, 가공 catalogue. 2026-11-02 수집 53,578건 중 교환대 Y 9,833건이며 571건만 이름·주소가 일치하는 공식 좌표가 있다. 좌표 없는 시설을 근처라고 추정하지 않는다.
- `npm run data:outing`: 원본을 검증하고 catalogue를 재생성. 빌드의 `--check`로 재현성을 확인한다. 원본은 해당 API 서버 배포에만 포함하며 공개 URL로 제공하지 않는다.

## 현재 운영 중인 병원·약국

국립중앙의료원의 `getHsptlMdcncListInfoInqire`(QD=D002)와 `getParmacyListInfoInqire`에서 전국 목록·좌표·요일별 시간을 조회해 페이지별로 24시간 공유한다. 모든 페이지의 개수·ID를 검증하며 정확한 기기 위치는 외부 의료 API에 보내지 않는다.

기상청 특일 API `getRestDeInfo`의 공휴일과 한국 현재 시각을 적용한다. 공휴일은 휴일 시간만 사용하고 보통 요일 시간으로 대체하지 않는다. 운영시간·공휴일 조회 실패, 시간 누락·잘못된 시간·해석할 수 없는 야간 이월은 확인 불가로 처리해 추천에서 제외한다. 종료 시각은 닫힌 상태이며 응답을 만드는 시점에 다시 계산한다. 확인된 운영 중 시설 중 직선거리 20km 이내에서 가장 가까운 곳을 선택한다. 실시간 방문·휴진 여부를 확인하는 기능은 아니다.

## 날씨·미세먼지

기상청 초단기 실황·예보는 지역 기상 격자로 10분 공유, 에어코리아 관측값은 시도별로 30분 공유한다. 실제 위치와 대응하는 동네/구 측정소만 쓰며 다른 측정소를 임의 대체하지 않는다. 관측값이 없으면 기온·등급도 추정하지 않는다. 안개는 해당 API에 없어 만들지 않는다.

위치는 브라우저의 나들이 시작 제출 이벤트 안에서 요청한다. 권한 거절·브라우저 미지원은 기록 저장을 막지 않는다. 좌표는 DB·로그·분석에 남기지 않는다. 나들이 화면이 보이는 동안 5분마다, 다시 화면을 열 때 갱신하고 종료하면 타이머·리스너·요청을 정리한다. 일반 HTTP LAN 주소에서는 브라우저 위치 기능을 사용할 수 없다.
