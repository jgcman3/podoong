# 거주지역 기반 부모 커뮤니티

2026-10-15 요청: 지역별 게시판을 같은 시·군·구의 지역 게시판과 같은 읍·면·동의 동네 게시판으로 나누고, 주제별 게시판은 같은 국가에서 함께 이용합니다.

## 이용 방식

우리 가족에서 거주지역을 저장하면 커뮤니티에 자동 연결합니다. 가족이 여러 개면 가족 선택으로 기준을 바꿉니다. 아이가 달라도 같은 가족이면 같은 게시판을 이용합니다. 거주지역이 없으면 등록 화면으로 안내하며 임의로 지역·국가를 추정하지 않습니다.

| 구분          | 공유 범위     | 제목 예시     |
| ------------- | ------------- | ------------- |
| 지역 게시판   | 같은 시·군·구 | 강남구 게시판 |
| 동네 게시판   | 같은 읍·면·동 | 역삼동 게시판 |
| 주제별 게시판 | 같은 국가     | 먹이기 게시판 |

임신·출산·먹이기·건강·일상 주제를 제공합니다. 주제별 글을 지역 게시판에 자동 중복 게시하지 않습니다. 게시판 선택, 목록 제목, 글 상세, 작성·수정 화면에서는 마지막 지역명 또는 주제에 ‘게시판’을 붙여 표시합니다. 예: `강남구 게시판`, `역삼동 게시판`, `임신 게시판`. 국가·상위 지역명과 ‘지역/동네’ 접두 문구는 제목에서 생략하고, DB의 전체 명칭·국가·지역 키와 공유 범위는 유지합니다. 목록 → 별도 글쓰기 → 상세·댓글 순서를 유지합니다. 작성 화면에서는 게시판을 선택하고 제목·본문을 입력하며 지역을 직접 타이핑하지 않습니다.

## DB와 접근 범위

마이그레이션 `017`은 다음을 추가합니다.

- `residence_regions.community_scope`: 지역의 커뮤니티 역할(`district`/`locality`). 한국의 시군구·읍면동에 지정합니다. 국가별 행정구역 종류나 깊이와 별도로 설정하므로 해외에서도 같은 분류 구조를 사용할 수 있습니다.
- `community_boards`: 국가·범위·지역 또는 주제로 게시판을 식별합니다. 동일 지역·주제의 동시 요청도 같은 게시판으로 연결되도록 복합 유일 키를 둡니다. 지역은 기존 국가+지역 복합 외래 키를 사용합니다.
- `community_posts.board_id`: 글이 속한 게시판. 지역 게시판은 주제가 없어도 작성할 수 있고, 국가 주제 게시판은 해당 주제로 구분합니다. 기존 `region`·`topic` 필드는 표시값·내보내기 호환을 위해 유지하며 접근 범위 판단에는 사용하지 않습니다.

`community_board_locations()`는 로그인 사용자의 가족과 거주지역 계층을 확인해 국가·지역·동네 소속을 반환합니다. 등록된 가족 거주지역을 기준으로 하며 실거주 인증 기능은 없습니다. 여러 가족에 속하면 각각의 유효한 거주지역에 접근할 수 있습니다. 화면은 선택한 가족의 게시판만 조회합니다.

`community_command`는 새 글의 국가·지역을 가족 정보에서 결정합니다. 다른 가족 ID나 임의 지역을 보내 범위를 바꿀 수 없습니다. RLS는 목록·직접 상세 조회·댓글·공감·저장·사진에 같은 범위를 적용합니다. 사진 API도 매 요청마다 접근 권한을 확인합니다. 기존 운영자는 신고 처리를 위해 전체 범위를 조회할 수 있으며 차단·숨김·이용 제한은 유지합니다.

새 글은 `018`에서 작성 화면의 거주지역 버전을 확인하고 저장이 끝날 때까지 가족 주소 행을 잠급니다. 작성 중 주소가 바뀌면 변경된 지역에 자동 게시하지 않고 게시판을 다시 확인하도록 안내합니다.

글 수정은 제목·본문만 바꿉니다. 게시판을 이동시켜 기존 댓글·사진의 공유 범위가 바뀌는 것을 막습니다. 거주지역을 옮기면 기존 글은 원래 게시판에 남고 이전 지역 접근은 해제됩니다. 같은 국가 내 이사라면 국가 주제 게시판은 계속 이용합니다.

## 기존 글과 해외 확장

기존 글은 지역 문자열과 주제를 함께 갖고 전체 커뮤니티에서 읽을 수 있었습니다. `017`은 현재 한국 서비스의 기존 주제를 대한민국 주제 게시판에 연결합니다. 본문·댓글·사진을 삭제하지 않고 동네를 추정하지 않습니다. 이후 작성한 지역·동네 글은 해당 지역으로만 분리합니다.

새 국가를 지원할 때는 국가·지역 자료와 `community_scope` 역할을 등록하고 국가 선택·목록 조회·입력 검증을 구현합니다. 국가 주제 게시판은 첫 글 작성 시 국가별로 생성됩니다. 같은 주제라도 국가가 다르면 별도 게시판이며, 언어 전환은 국가를 바꾸지 않습니다.
