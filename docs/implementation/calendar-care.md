# 통합 일정과 빠른 등록

갱신: 2026-10-26

## 화면 흐름

- 오늘 기능 목록은 예방접종을 포함한 14종입니다. 오늘의 예방접종은 같은 하단 시트/PC 패널에서 접종 완료를 빠르게 기록합니다. 일정 메뉴의 예방접종 버튼은 기존 예정 등록 폼을 사용합니다.
- 일정과 할 일에는 일정·병원·예방접종·투약·할 일 버튼을 배치합니다. 선택한 등록 화면만 모바일·PC 공통 하단 시트로 엽니다. 제목·날짜 등 자주 쓰는 항목을 먼저 보여주고 메모·담당자 등은 상세 설정으로 접습니다. 저장하면 해당 날짜로 돌아갑니다.
- 병원·투약 예정은 날짜·선택적 시간과 메모를 저장합니다. 투약 예정은 실제 복용 기록과 구분합니다. 실제 투약량·복용 기록은 오늘 화면의 기존 돌봄 기록을 사용합니다.
- 일반 일정·병원·투약·예방접종은 월간 달력의 색상 표식으로 모아 보고, 선택한 날짜의 목록을 아래에 표시합니다. 할 일은 기존 담당자·상태·마감일을 유지합니다.
- 오늘의 다가오는 일정도 같은 자료에서 조회합니다. 완료된 접종은 다가오는 일정에서 제외하며, 별도 예방접종 영역은 중복되지 않게 제거합니다.

## 저장과 접근 권한

마이그레이션 `021_calendar_care`는 `events`에 종류(`general`, `hospital`, `medication`), 선택적 시각, 입력 시간대를 추가합니다. 기존 일정은 일반 일정으로 유지하고 미확인 시각·시간대를 추정하지 않습니다. `save_calendar_event`는 아이 쓰기 권한과 시간대를 검사하고 감사 기록을 남깁니다. 기존 `save_event` 호출도 유지하며 새 메타데이터를 지우지 않습니다.

`calendar_entries`는 일반 일정과 기존 `vaccination_records`를 합치는 읽기 전용 뷰입니다. `security_invoker=true`로 원본 테이블의 가족·아이 접근 권한을 적용합니다. 접종을 일정 테이블에 복사하지 않으므로 수정·완료·삭제가 다음 조회에 반영되고 중복 자료가 생기지 않습니다. 달력의 접종 수정·삭제도 원래 예방접종 저장 함수와 버전 검사를 사용합니다. 내보내기는 원래 자료 구조를 유지합니다.

## 검증

- 이번 UI 변경의 단위 테스트 73개 통과. DB 구조 변경은 없으며 기존 PostgreSQL 검증 340개와 정리 검증 10개를 기반으로 합니다.
- 최신 변경 관련 브라우저 동선 4개에서 월간 일정 120건·선택 날짜 할 일 105건 조회, 날짜 탐색, 하단 시트 등록, 마우스·터치의 전체 스와이프 실행, 부분 스와이프·Escape 취소, 접종 원본 수정·삭제와 오늘 화면의 날짜별 카드를 확인했습니다.
- 병원·투약의 시각 저장, 예방접종 날짜 수정 반영, 모바일 시트, 조회 전용 가족과 관계없는 사용자의 접근 제한을 검증했습니다.

## 날짜별 오늘 카드와 목록 정리 — 2026-10-26

오늘 화면의 ‘오늘 할 일’과 ‘오늘 일정’은 설정된 시간대의 오늘 날짜에 해당하는 자료가 있을 때만 카드 전체를 표시합니다. 날짜가 없거나 과거·미래인 항목은 오늘 카드에 표시하지 않습니다. 오늘 할 일에는 오늘이 마감일인 할 일과 완료된 할 일을 포함하고 미룬 항목은 제외합니다. 오늘 일정에는 오늘 날짜의 예정 일정·예방접종을 표시합니다. 날짜 전환은 기존 오늘 화면의 갱신 흐름을 따릅니다.

오늘 화면의 할 일 목록은 왼쪽 체크박스로 완료·해제하며, 성공 시 리다이렉트 없이 현재 위치에서 자료를 갱신합니다. 오른쪽 상태 배지·체크 버튼은 표시하지 않습니다. 조회 전용 가족의 체크박스는 비활성화됩니다. 오늘 화면의 할 일 추가·전체 할 일 보기·일정 전체 보기 링크는 제거합니다. 추가와 상세 편집은 일정과 할 일 메뉴에서 처리합니다.

일정 메뉴의 눈에 보이는 페이지 제목은 제거하고, 할 일 목록은 ‘해야 할 일’로 표시합니다. 일정은 아래 월간 달력 흐름을 따릅니다. 상단 기능 아이콘에 일반 ‘일정’을 추가해 다섯 가지 등록을 지원하며, 일정 목록 안의 별도 일정 추가 버튼은 제거합니다. 일반 할 일(`general`)은 `022_general_tasks`의 허용 분류를 사용하고 기존 아이별 권한·담당자 검사를 유지합니다.

브라우저 동선 3개에서 일반 일정 등록, 오늘 날짜에 맞는 카드 표시·숨김, 날짜 변경 후 반영, 오늘 목록의 완료·해제와 조회 전용 가족의 권한을 확인했습니다. 기존 병원·접종·투약 등록도 통과했습니다.

## 월간 달력·스와이프 편집 — 2026-10-26

- 일정 메뉴의 모든 추가·수정은 화면 하단에서 올라오는 시트를 사용합니다. 모바일은 전체 폭, PC는 최대 580px로 표시하며, 동작 줄이기 설정을 존중합니다. 닫기·Escape는 선택 날짜로 돌아갑니다.
- 월간 달력은 이전·다음 달, 오늘 복귀, 날짜 선택을 제공합니다. 종류별 색상 표식과 건수를 표시하며 선택한 날짜의 일정만 아래에 나옵니다. 일정과 할 일 모두 해당 월의 자료를 500건 단위로 끝까지 조회하므로 기존 100건 제한으로 누락되지 않습니다. 날짜를 선택하면 그날의 일정과 할 일만 표시합니다. 날짜 미지정 할 일은 달력 날짜 목록에 포함하지 않으며 원본 자료는 유지합니다.
- 일정 메뉴의 할 일에는 왼쪽 완료·해제 체크박스를 표시합니다. 할 일과 일정 모두 짧은 스와이프는 오른쪽 수정·왼쪽 삭제 버튼을 드러내며, 끝까지 밀어 놓으면 오른쪽은 수정 시트를 열고 왼쪽은 확인창 없이 바로 삭제합니다. 부분 이동 후 삭제 버튼을 누르면 기존 확인창을 사용합니다. 점점점 메뉴는 제거하고, 키보드는 카드의 수정·삭제 작업에 포커스하면 버튼이 드러납니다. 마우스·터치와 세로 스크롤을 지원합니다. 완료·해제는 체크박스로, 미룸 등 상세 상태는 수정 시트에서 바꿉니다.
- 오늘 화면의 체크박스와 오늘 날짜에만 나오는 카드 규칙은 유지합니다. 조회 전용 가족은 달력·목록만 보고 편집 시트·스와이프 작업을 사용할 수 없습니다. 수정 조회는 아이 ID까지 확인하고 원래 저장 RPC의 권한 검사도 유지합니다.
- 날짜 변경 후 저장은 변경된 날짜를 선택하고, 삭제 후에는 보고 있던 날짜를 유지합니다. 예방접종은 원본 한 건을 수정·삭제하며 별도 일정 레코드를 만들지 않습니다.

## 날짜별 간결한 목록과 전체 스와이프 — 2026-10-26

일정 목록의 반복 날짜 제목과 할 일 카드의 반복 날짜를 제거하고 카드·목록 여백을 줄입니다. 월간 달력은 해당 월에 필요한 4~6주만 표시합니다. 할 일도 달력에 표식과 건수로 나타내고 선택 날짜로 조회합니다. 조회 전용 가족은 편집 작업이 제공되지 않습니다. 끝까지 미는 제스처는 손을 놓을 때 실행하며, 중간에 되돌리거나 터치가 취소되면 실행하지 않습니다.

## 할 일 완료 체크박스 — 2026-10-26

일정 메뉴의 ‘해야 할 일’ 제목은 화면에서 제거하고 영역의 접근성 이름은 유지합니다. 각 항목 왼쪽 체크박스로 완료·해제하며, 완료한 제목에는 취소선을 표시합니다. 체크박스 클릭은 드래그로 처리하지 않으며 좌우 전체 스와이프의 수정·삭제는 함께 제공합니다. 오늘 화면과 같은 체크박스 컴포넌트를 사용하고 기존 저장 RPC와 권한 검사를 재사용합니다. 성공 시 리다이렉트 없이 목록과 오늘 화면을 갱신해 선택 날짜·스크롤 위치를 유지합니다. 조회 전용 가족의 체크박스는 비활성화됩니다.

## 드래그 아이콘과 빈 목록 — 2026-10-26

스와이프의 수정·삭제는 연필·휴지통 아이콘만 표시하며, 스크린리더용 작업 이름과 키보드 접근은 유지합니다. 일정·예방접종·할 일에 동일하게 적용합니다. 빈 할 일 문구는 ‘등록된 할일이 없어요’이며 빈 일정과 같은 패딩·문단 여백을 사용해 영역 높이를 맞춥니다.

일정 카드의 시간(미지정 시 종일)·종류·제목은 한 줄에 배치합니다. 긴 제목은 남은 폭에서 줄바꿈하고 좁은 화면에서는 다음 줄로 이어지며, 병원·메모는 아래에 표시합니다.

## 선택 날짜에 속하는 일정·할 일 — 2026-10-26

캘린더와 선택 날짜의 목록을 하나의 카드로 묶습니다. PC는 캘린더 옆에, 모바일은 아래에 같은 날짜의 두 목록을 표시합니다. 공통 날짜 제목은 선택한 칸과 같은 강조색을 사용하며 ‘일정’·‘할 일’ 소제목으로 구분합니다. 날짜 제목은 두 목록 위에서 한 번만 표시합니다. 날짜 전환 시 제목과 두 목록이 함께 갱신되며 인라인 일정 제목·완료 체크박스·아이콘 스와이프 동작은 유지합니다.

## 오늘 목록 간소화 — 2026-10-26

오늘 할 일은 체크박스와 제목만 표시하고 반복 날짜·서비스·생성 출처·담당자 정보는 상세 목록에 남깁니다. 오늘 일정은 시간(미지정 시 종일)·종류·제목을 한 줄로 표시하고 날짜 블록·‘오늘’ 배지·병원·메모의 반복 노출은 제거합니다. 두 목록은 PC에서 나란히, 모바일에서 위아래로 배치하며 항목별 중첩 카드를 줄이고 얇은 구분선을 사용합니다. 날짜별 카드 표시 조건, 완료·해제, 조회 전용 권한과 예방접종 상세 링크는 유지합니다.

후속 요청으로 목록 위 공통 날짜·요일 제목은 제거했습니다. 날짜는 캘린더의 선택 표시로 구분하고, 하나의 카드 안에서 ‘일정’·‘할 일’ 소제목과 선택 날짜의 두 목록만 유지합니다.

## 오늘 기록 날짜와 할 일·일정 통합 — 2026-10-26

오늘 화면의 할 일·일정은 날짜별 기록 카드 안에서 같은 날짜 제목 아래 표시합니다. 과거 날짜로 이동하면 기록·섭취량·그날의 할 일·예정 일정도 함께 조회합니다. 해당 날짜의 자료가 없으면 소제목과 영역은 숨깁니다. 오늘은 기존 제목, 과거 날짜는 ‘할 일’·‘일정’으로 표시합니다. 완료 접종은 기록에만 나오며 예정 일정에 중복 표시하지 않습니다.

날짜·아이 ID를 검증하는 서버 액션과 RLS로 조회하며 날짜 조건을 페이지 제한 전에 적용하고 500건 단위로 모두 읽습니다. 날짜를 다시 선택할 때 새로 조회해 오래된 상태를 재사용하지 않습니다. 과거 할 일도 완료·해제할 수 있고 성공한 저장 결과를 선택 날짜에 반영하며 오늘 자료는 서버 재검증으로 갱신합니다. 조회 전용 가족은 체크박스를 사용할 수 없으며 제출 중에는 중복 클릭을 막습니다. 진행 중 타이머는 기존처럼 오늘의 독립 영역에 유지합니다.

## 두 메뉴의 목록 카드 통일 — 2026-10-26

오늘 화면과 일정 메뉴는 공통 `AgendaEventCard`·`AgendaTaskCard`를 사용합니다. ‘일정 → 할 일’ 순서, 소제목, 카드 여백·모서리·글자 크기·종류별 배경색·완료 체크박스와 취소선이 동일합니다. 일정의 시간·종류·제목·병원·메모도 같은 형식으로 표시합니다. 오늘 화면에서는 기존 날짜별 기록 영역 안에서 선택 날짜의 자료만 표시합니다.

## 메뉴 진입점 정리 — 2026-10-26

모바일 하단 메뉴는 오늘·일정과 할 일·우리 가족·전체 서비스 네 가지입니다. 공통 상단의 커뮤니티·오늘의 질문·알림·데이터 관리 바로가기를 제거하고 전체 서비스에서 진입합니다. 전체 서비스에는 알림·데이터 관리 카드를 추가하고 커뮤니티는 선택 가족을 유지합니다. 계정 설정의 별도 데이터 관리 바로가기도 제거합니다. 돌봄 기록 페이지와 먹이기 서비스의 기록 기능은 유지합니다.
