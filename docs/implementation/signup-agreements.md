# 가입 동의 흐름

작성일: 2026-10-30 · 상태: 개발용 초안 동의 흐름 구현

## 화면 순서

1. 카카오 등 소셜 인증으로 로그인한다. 제공자 동의는 포둥 약관 동의를 대신하지 않는다.
2. `/[locale]/onboarding`에서 이용약관과 가입 개인정보 수집·이용 안내를 각각 선택한다. 처리방침·수집 목적/항목/기간/거부 영향도 열람한다.
3. 서버가 두 문서의 현재 버전과 선택을 확인하고 저장한 후 보호자·아이 입력을 표시한다. 초대받은 보호자는 아이를 새로 등록하지 않는다.

미선택 상태가 기본이며 ‘동의하지 않고 나가기’는 로그아웃한다. 약관 열람·관련 문서 이동에서도 초대 복귀 경로를 유지한다. 영어 UI는 제공하지만 현재 전문의 실제 언어는 한국어라고 명시한다.

## 저장과 권한

- `signup_document_versions`: 문서 종류·버전·원문 언어·고정 전문·서버 계산 SHA-256·초안 상태. 문서별 현재 버전은 하나다.
- `signup_agreements`: 인증 계정·문서 종류/버전·화면 언어·서버 시각. 고정 문서를 외래키로 참조하며 같은 동의를 다시 보내도 최초 기록을 유지한다.
- 브라우저는 문서를 읽고 자신의 동의 내역만 조회한다. 동의 저장은 `accept_signup_agreements` RPC에서 두 항목을 원자적으로 기록한다. 다른 계정·오래된 버전·부분 동의·직접 프로필 생성으로 우회할 수 없다.
- 관리자 임포트는 별도 신뢰 경로로 남기며 기존 계정의 `consented_at`를 새 문서 동의로 소급하지 않는다. 일반 데이터 조회에는 새 조인이나 동의 조회를 추가하지 않았다.
- 계정 삭제 시 인증 계정 외래키를 통해 동의 이력도 삭제된다. 아이·가족 기록은 이번 마이그레이션에서 변경하지 않는다.

## 버전 변경과 한계

현재 버전은 `signup-2026-10-30-draft.1`이다. 061 마이그레이션의 고정 사본은 이후 편집한 문서와 섞지 않는다. 새 문안은 새 버전·새 사본으로 추가하고 기존 계정의 재동의 범위를 결정한다.

개발 초안 동의는 정식 서비스 약관 시행·법적 요건 완료를 뜻하지 않는다. 아동별 법정대리인 확인·건강정보·일기 공개/공유·국외 이전은 가입 동의로 허용되지 않으며 별도 구현/검토가 남아 있다. 정식 공개 전에 약관 시행과 보관/위탁 정책을 확정해야 한다.

## 검증

로컬 SQL 검사는 미동의/부분 동의/이전 버전 거부, 직접 프로필 생성 차단, 자기 내역만 조회, 문서 변경 권한 차단, 중복 제출과 계정 삭제를 확인한다. 브라우저 검사는 두 필수 선택 전 입력 차단, 전문 왕복, 모바일 폭, 한글 신규 가입, 동의 거부 및 영문 초대 가입을 확인한다.
