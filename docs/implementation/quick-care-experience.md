# 3초 육아 기록

2026-10-25: 첨부한 모바일 기록 화면의 큰 터치 영역·양 눈금·타임라인을 참고해 오늘 화면의 빠른 기록을 재구성합니다. ‘3초’는 짧은 조작 흐름을 위한 컨셉이며 실제 저장 시간은 네트워크 상태에 따라 달라집니다.

## 화면과 흐름

- 오늘 화면 상단은 마지막 기저귀·식사·수면 요약을 표시합니다. 인사·초대 영역과 다음 먹이기 카드는 제거하고 그 아래에서 모유·분유·이유식·기저귀·배변·수면·목욕·병원·체온·투약·간식·놀이·터미타임을 바로 기록합니다.
- 데스크톱은 항목을 선택했을 때 오늘 기록과 입력 패널을 나란히 배치합니다. 900px 이하에서는 동일한 입력 패널을 하단 모달 시트로 전환합니다. 크기를 바꿔도 선택한 양·시간·메모를 유지합니다.
- 분유·이유식은 큰 양 표시, 드래그 가능한 세로 눈금, 자주 쓰는 양 버튼을 제공합니다. 키보드로도 눈금을 조작할 수 있습니다. 분유·새 이유식은 ml로 기록하며 ‘양 모름’은 NULL로 저장합니다.
- 모유는 타이머 시작 또는 먹인 시간 선택으로 기록합니다. 수면은 낮잠·밤잠을 선택하고 시작·종료하거나 이미 완료된 시간을 기록합니다. 진행 중인 기록은 타임라인 위에 고정 표시합니다.
- 기저귀는 소변·대변·혼합·단순 교체를 선택하고 저장합니다. 성장·발달은 기존 상세 입력 화면으로 연결합니다.
- 시각과 메모는 펼침 항목으로, 대변 상태 등 추가 항목은 ‘자세히 기록’에서 입력합니다. 기존 수정·사진·다음 먹이기 설정 기능도 유지합니다.

저장은 화면 이동 없이 처리하고, 성공 응답을 받은 뒤 오늘 기록과 다음 먹이기를 갱신합니다. 저장 중 중복 제출과 기록창 전환·닫기를 막습니다. 실패하면 입력값을 유지하고 오류를 표시합니다. 모바일 모달은 브라우저의 포커스 제한과 Escape 닫기를 사용하고, 배경 스크롤을 막습니다. 움직임 감소 설정을 존중합니다.

## 데이터 정확도와 권한

`care_records`, `child_records`와 기존 저장 RPC를 사용합니다. DB 스키마 변경은 없습니다. 일반 먹이기 저장과 빠른 저장은 `feeding-schema.ts`의 검증을 공유합니다.

완료된 먹이기는 **실제 먹인 시간**을 선택해야 저장합니다. ‘방금 먹였어요’에서 시간을 고르면 현재 시각에서 해당 시간을 뺀 시작 시각을 제안하며 직접 변경할 수 있습니다. 소요 시간을 임의로 추정하거나 0으로 채우지 않습니다. 양 눈금의 초기값·선택 후보는 빠른 입력을 위한 값이며 권장 섭취량을 의미하지 않습니다. 사용자는 표시된 양을 확인하거나 변경하고 저장합니다.

지금 시작하는 수유·수면 타이머와 현재 시각의 기저귀 기록은 서버가 받은 요청 시각을 사용합니다. 종료 시에는 서버 시각과 기존 시작 시각을 사용해 초 단위 경과를 보존합니다. 종료 요청은 기존 메모·양·종류·시간대를 보존하고 수정 버전 충돌을 검사합니다.

조회 전용 보호자는 기록 종류 대신 기존 조회 화면 링크와 타임라인을 이용합니다. 서버에서도 사용자 인증과 기존 RPC의 아이별 쓰기 권한을 확인합니다. 타이머 중복·수면 중복·동시 수정은 기존 DB 제약으로 검증합니다. 통계 화면과 그래프는 추가하지 않습니다.

## 날짜 스와이프와 최근 돌봄 요약 — 2026-10-26

기록 영역을 오른쪽으로 밀면 이전 날짜, 왼쪽으로 밀면 다음 날짜를 조회합니다. 스크롤바 없이 마우스 드래그·터치·키보드 방향키를 지원하며, 날짜 옆 화살표와 오늘 복귀 아이콘도 제공합니다. 미래 날짜는 조회하지 않습니다. 선택 날짜의 기록·요일·분유/이유식 합계가 함께 바뀌고, 진행 중인 수유·수면은 별도 영역에 유지합니다.

과거 자료는 인증된 서버 액션으로 날짜별 조회하며 기존 아이 접근 권한을 적용합니다. 읽기 권한만 있는 가족도 과거 기록을 볼 수 있습니다. 방문한 날짜는 화면 안에서 재사용하며 저장하면 오늘로 돌아가 자료를 새로 읽습니다. 불러오기 실패 시 현재 날짜와 기록을 유지하고 재시도를 제공합니다. 날짜 이동 중 링크가 잘못 열리지 않게 클릭과 드래그를 구분합니다.

‘아이 이름의 하루’ 제목·보호자 초대 링크·다음 먹이기 카드를 제거했습니다. 상단 3개 요약은 마지막 기저귀, 마지막 식사(모유·분유·이유식), 마지막 수면입니다. 선택한 과거 날짜와 관계없이 아이의 가장 최근 기록을 보여주고, 몇 분/시간/일 전인지 30초마다 갱신합니다. 식사는 시작 시각, 완료된 수면은 기상 시각을 기준으로 하며, 진행 중인 수면은 경과 시간과 수면 중 상태를 표시합니다. 기록이 없으면 ‘기록 없음’을 표시합니다. 기존 수유·이유식 시간 설정 자료는 삭제하지 않습니다.

### 상단 아이 선택 — 2026-10-26

오늘의 예방접종 버튼도 다른 항목과 같은 입력 패널을 사용합니다. 모바일에서는 하단 시트, PC에서는 기록 옆 패널로 열리며 화면 이동 없이 저장합니다. 기본 백신을 임의 선택하지 않고 사용자가 백신 버튼을 누른 뒤 접종 완료 기록을 저장합니다. 접종일 기본값은 설정된 시간대의 오늘이며 차수·병원·메모는 펼쳐서 선택 입력합니다. 알 수 없는 차수는 NULL로 저장하고 예정일·접종 시각을 만들지 않습니다.

저장은 기존 접종 권한·검증·버전 규칙을 사용하는 `save_vaccination_record`에 연결합니다. 일정 메뉴의 예정 등록 흐름은 유지합니다. 완료 접종은 날짜별 돌봄 목록과 기존 접종 상세·통합 일정에서 조회합니다. 접종일만 있는 자료는 실제 접종일로 분류하며 등록 시각을 접종 시각처럼 표시하지 않습니다. 과거 접종일도 해당 날짜에서 조회하고 섭취량 합계에는 포함하지 않습니다.

단위 테스트 70개와 브라우저 동선 3개가 통과했습니다. 모바일 시트·PC 전환 중 선택 유지, 이동 없는 저장, 과거 접종일·선택 입력·상세 조회·일정 반영과 기존 기록 동선을 확인했습니다.

### 오늘 카드의 최종 표시 규칙 — 2026-10-26

### 날짜별 기록·할 일·일정 한 영역 — 2026-10-26
