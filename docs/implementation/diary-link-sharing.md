# 아이별 성장일기 링크 공유

- ‘우리 아이 성장일기’ 상단에서 가족 편집 권한이 있는 보호자가 아이별 링크 하나를 관리한다. 개별 일기 및 다른 아이의 공개 피드에는 공유 버튼을 두지 않는다.
- 공유 창을 열기만 하면 공개되지 않는다. 공개 범위 안내를 확인하고 ‘공유 링크 만들기’를 눌러야 활성화된다.
- 링크 방문자는 로그인 없이 해당 아이의 닉네임, 공개 일기의 날짜·글·사진을 최신순으로 본다. 처음 20개를 조회하고 목록 끝에 가까워지면 과거 20개를 이어서 불러온다. 로딩 실패 시 다시 시도 버튼을 제공하며, 비공개·관리자 숨김·미래 기록은 제외한다. 가족 정보, 주소, 생년월일, 성장 수치는 반환하지 않는다.
- 새 공개 일기는 기존 링크에 자동으로 표시된다. 비공개 전환·삭제는 목록과 사진의 다음 요청부터 반영된다. 외부 방문자가 이미 저장한 자료는 회수할 수 없다.
- ‘링크 복사’, ‘공유 링크 끄기’, ‘새 링크 발급’을 제공한다. 새 링크를 발급하면 이전 링크는 종료된다.
- `child_diary_links`의 256비트 무작위 토큰을 사용한다. 테이블 직접 접근은 차단하고 관리 RPC는 아이의 가족 편집 권한을 검사한다. 생성자의 계정 삭제 요청이나 편집 권한 상실 시 링크는 무효다.
- `child_diary_link_records`가 목록과 사진에 공통 공개 조건을 적용한다. 사진 프록시는 익명 RPC로 토큰과 사진 소속·공개 여부를 먼저 검사한 후, 서버 전용 키로 승인된 정확한 파일만 읽는다. 버킷은 비공개이며 키나 Storage URL을 브라우저에 전달하지 않는다.
- 공유 페이지와 사진은 캐시하지 않고 검색엔진 색인 및 리퍼러 전달을 막는다. 소셜 미리보기에는 포둥 브랜드만 넣는다.
- 페이지 하단에 포둥 소개와 시작하기 링크를 제공한다. 추후 광고는 목록 사이 또는 하단에 배치할 수 있으며, 현재 광고와 빈 광고 영역은 없다.

## 전환 및 실행 환경

마이그레이션 `202610270034_child_diary_links.sql`은 기존 개별 일기 공유 링크와 해당 관리 함수를 제거한다. 기존 토큰을 아이 전체 링크로 재사용하지 않는다. 보호자가 아이별 링크를 새로 생성해야 한다.

서버에는 같은 프로젝트의 `SUPABASE_SECRET_KEY` 또는 `SUPABASE_SERVICE_ROLE_KEY`가 필요하다. `NEXT_PUBLIC_` 접두사를 사용하지 않는다. 키가 없으면 사진 요청은 503으로 종료되며 권한 검사를 생략하지 않는다.

URL은 접속한 origin을 기준으로 생성한다. `192.168.*` 주소는 같은 네트워크에서만 접속할 수 있으므로 외부 공유에는 공개 도메인이 필요하다. 배포 시 `NEXT_PUBLIC_SITE_URL`도 설정한다.

## 검증

`supabase/tests/diary_links.test.sql`은 관리 권한, 공개 범위, 비공개 전환 후 이미지 차단, 링크 종료를 검사한다. 모바일 E2E는 공유 버튼 위치, 익명 페이지·사진 조회, 폐기 후 차단을 확인한다. `tests/unit/diary-link-photo.test.ts`는 서버 이미지 조회 전에 공유 권한을 검사하는지 확인한다.

## 공유 화면 디자인

공유 페이지는 자체 호스팅 나눔스퀘어라운드 글꼴과 Lucide 선 아이콘을 사용한다. 네이버 공식 배포처의 정규·굵은 WOFF2 파일을 사용하며 출처와 저작권 정보는 `public/fonts/nanum-square-round-LICENSE.txt`에 보관한다. 공유 종료 화면에도 동일한 글꼴을 적용한다. 글꼴 교체 중에도 시스템 글꼴로 바로 읽을 수 있도록 `font-display: swap`을 사용한다.

따뜻한 아이보리 배경, 흰 카드와 절제된 테두리로 사진·글을 강조한다. 빈티지 종이 질감, 명조체, 테이프 및 반복 장식은 사용하지 않는다. 카드 간격은 52px로 유지하고, 사진은 원본 비율로 표시하고 원본 크기 이상으로 확대하지 않는다. 현재 사진에 맞춰 갤러리 높이를 조절하며 여러 장은 가로 스와이프로 본다.

공유 화면은 목록 위 작은 소개 안내와 시작하기 버튼을 제공해 일기가 길어져도 묻히지 않게 한다. 종료 화면 하단은 브랜드, “함께 돌보는, 포근한 둥지” 문구, 한 줄 소개와 시작하기 버튼으로 구성한다. 종료 화면에는 아이 정보를 노출하지 않는다. 앱 내 목록 상단은 왼쪽 ‘일기장 공유’ 보조 버튼과 오른쪽 ‘일기 쓰기’ 강조 버튼으로 역할을 구분한다.

정상 페이지와 공유 종료 화면은 `SharedDiaryFrame`, `SharedDiaryHeading`, `SharedDiaryInvite`를 공통 사용한다. 스타일 루트도 각 화면이 직접 포함해 새로고침·직접 접근 시 동일한 글꼴과 배경을 유지한다. 브라우저 테스트는 두 화면의 글꼴·색·아이콘·여백을 비교한다.

공유 링크의 `/ko/` 또는 `/en/`은 생성 당시 보호자가 앱에서 사용 중인 언어를 따른다. 방문자는 공통 헤더의 언어 전환으로 한국어·영어 UI를 바꿀 수 있으며 종료 화면도 같은 전환을 제공한다. 일기 본문과 아이 닉네임은 원문 그대로 유지한다.

공유 화면은 기본 우클릭 메뉴와 Ctrl/Cmd+S 저장 단축키를 제한한다. 사진에는 드래그 저장과 지원되는 모바일 브라우저의 길게 누르기 메뉴 제한을 적용하되 가로 스와이프·세로 스크롤은 유지한다. 이는 일반적인 저장 동작을 억제하는 UI 조치이며 스크린샷·개발자 도구·직접 이미지 요청까지 차단하는 보안 기능은 아니다.
