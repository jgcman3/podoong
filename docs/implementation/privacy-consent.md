# 가입 동의·개인정보 운영 연결

기준일 2026-11-03 · 문서 묶음 `signup-2026-11-03-v1`

## 채택한 흐름

소셜 로그인 → 가입 동의(이용약관·기본 개인정보+권한 선언·가입 필수 건강정보) → 가족 참여 또는 새 가족/아이 입력 → 서비스 이용 순서입니다. 일기는 기본 비공개이며 공개/공유를 직접 선택할 때, 동네 놀이터는 아이별 최초 참여를 선택할 때 안내와 선택을 받습니다. 소셜 로그인만으로 가입 동의를 완료했다고 보지 않습니다. 문서·선택은 서버에서 검증하고 서버 시각·문서 버전/해시·불변 원문 스냅샷과 연결합니다.

필수 약관과 필수 보호자·아이 기본 개인정보 수집·이용을 구분하고, 아동 처리 권한 선언은 기본 개인정보 항목에 함께 명시합니다. 가입 시 건강정보 처리 동의도 필수로 받으며, 일반 개인정보 동의와 별도 항목으로 표시합니다. 일기 공개·공유는 공개할 때, 놀이터는 아이별 최초 참여할 때 안내하고 선택을 받습니다. 새 일기는 기본 비공개이며 놀이터 선택은 해당 아이에게 유지됩니다. 가입 필수 세 항목은 미리 체크하지 않습니다. 공개·참여를 선택하지 않아도 나머지 기능은 이용할 수 있습니다. 각 동작의 선택과 시각·문서 버전을 저장합니다. 기능 시점마다 재동의 팝업을 만들지 않고 미선택 기능은 설정의 동의 관리로 연결합니다.

기존 동의를 단순 체크 상태로 대체하거나 서비스 이용만으로 소급 생성하지 않습니다. 법적 목적·항목이 변경되면 필요 동의를 받을 수 있지만 단순 기능 진입 때 같은 동의를 반복하지 않습니다. 운영 DB에 새 스키마·원문이 실제 적용되어야 해당 버전이 배포된 것으로 봅니다.

## 가입자 권한 선언

가입 화면의 필수 체크박스로 로그인한 성인 보호자가 아이의 법정대리인 또는 적법하게 권한을 위임받았음을 선언합니다. 문서 버전·해시·계정·서버 시각·선택 항목을 기록하고, 체크 후 가족 참여 또는 아이 등록으로 바로 진행합니다. 별도 메일 발송·인증 코드·Resend·인증용 이메일 수집·메일 대기 화면은 없습니다.

가입자 선언과 친권·가족관계의 실제 인증을 구분합니다. 체크박스만으로 법정대리인 동의 확인 요건까지 충분히 충족한다고 보장하지 않으며 출시 전 법적 적합성 확인 사항으로 남깁니다. 분쟁·무단 등록 의심 시 접근·공개를 제한하고 필요한 최소 자료로 확인합니다.

## 서버에서 보장할 선택 효과

| 선택           | 활성화                                       | 철회·미선택                                                         |
| -------------- | -------------------------------------------- | ------------------------------------------------------------------- |
| 건강           | 민감 기록 입력·분석 및 허용된 건강 수치 사용 | 서버의 입력·조회·분석 경로 제한, 해당 목적 기록·파생 첨부 삭제/정리 |
| 공개 일기/링크 | 공개 일기·공유 링크, 개별 비공개 우선        | 기본 비공개, 공개 목록·미로그인 링크·이미지 경로 차단, 링크 종료    |
| 놀이터         | 같은 동네 공개 프로필·출석·상태·상호작용     | 목록·폴링·행동 RPC에서 참여 제외, 프로필과 관련 데이터 정리         |

선택 동의가 있어도 다른 가족의 권한·아이에 대한 적법한 대리권을 자동 부여하지 않습니다. 사진·하루 패턴/기록 이미지에 포함된 민감 내용도 처리 대상입니다. 공개 철회와 원본 삭제는 구분하며 이미 내려받은 외부 사본의 회수는 약속하지 않습니다.

DB 정리만으로 Storage·Auth 삭제가 끝난 것으로 보고하지 않습니다. 기존 운영 작업 실행기·정기 작업·실패 알림을 실제 배포 환경에 연결해야 합니다. 외부 제공자 백업·CDN·로그는 구독 상품의 실제 만료를 기록하며 확인되지 않은 공통 만료일을 약속하지 않습니다. 삭제 대상의 복원 재노출을 막도록 삭제 요청을 복원 후 다시 적용합니다.

## 메일·인프라 외부 설정

세 도메인 별칭 support/privacy/admin은 Cloudflare Email Routing 무료 전달을 이용해 **운영자 Gmail 한 개**로 받습니다. 유료 Workspace나 세 개 계정은 필요하지 않습니다. 이 문서에 개인 Gmail 주소를 공개하지 않으며 일반 사용자에게 admin을 문의 창구로 제시하지 않습니다. 운영자가 2026-11-03 세 주소의 Gmail 전달 수신을 확인했습니다. Gmail에서 직접 답장하면 개인 주소가 드러나므로 도메인 발신 경로를 별도로 검증합니다.

Supabase 개발·운영 서울, Vercel 계산 icn1과 글로벌 CDN·로그·지원 처리를 구분합니다. Cloudflare/Google의 문의 메일 처리도 처리방침에 포함합니다. 공급자 DPA·재수탁 국가·로그/메일 보유 설정을 실제 계정의 상품과 비교하고 필요한 국외 처리 고지를 확인해야 합니다. 모든 저장을 한국이라고 안내하거나 공개 업체 목록을 최종 계약 검증의 대체물로 삼지 않습니다.

## 적용 확인·출시 전 남은 일

- 운영자: 세 주소의 문의 수신 연결 완료. 도메인 주소로 답장이 필요한 경우 발신 경로는 별도 설정. 가입 확인 메일 발송 설정은 불필요.
- 배포 담당: 환경별 DB 마이그레이션·고정 원문 스냅샷·서버 선택 제한·설정 철회·삭제 큐와 정기 보유기간 정리 적용. 운영 스키마가 개발보다 뒤처져 있으면 먼저 차이를 확인.
- 운영 담당: 백업 30일 정책의 자동 정리·복원 재삭제, 삭제 작업 실패 감시, 문의 메일 180일 정리, 공급자 로그 만료·국외 처리 국가/재수탁 목록 기록.
- 법적 확인: 가입자 선언 체크박스의 법정대리인 동의 확인 요건 적합성, 위임 보호자 참여 시 실제 법정대리인과의 연결, 공개 아동·건강정보 제공 근거, 계약 이행 국외 위탁 범위. 검토 없이 법적 인증 완료 또는 글로벌 준수를 표기하지 않음.
- 사용자 확인: 선택 미동의로 일반 기능 이용 가능, 공개/건강/놀이터 철회 후 관련 서버 응답·이미지 차단, 삭제 실패 재시도. 전체 회귀 검사는 별도 작업 범위에서 수행.

한국어 문서만 완전한 법률 원문으로 준비되어 있습니다. 영어 가입 안내를 제공하더라도 완전한 영어 법률 문서가 있다고 안내하지 않습니다. 광고·마케팅·외부 분석 SDK를 새로 도입하기 전 사업자·계약·국외 처리·동의 절차를 다시 검토합니다.

## 가입 필수 정책 변경 (2026-11-03)

운영자 요청으로 건강정보 동의는 가입 시 필수로 표시·검증합니다. 모두 동의는 세 개의 개별 체크를 함께 선택하는 편의 기능이며 독립된 포괄 동의 증빙으로 대체하지 않습니다. 서버는 각 동의와 문서 버전을 검증하고 미리 체크하지 않습니다. 가입 후 철회 권리와 관련 정보 삭제·기능 제한은 유지합니다. 건강정보가 전체 서비스 가입에 불가피한지에 대한 법적 필수성 검토는 구현과 별개로 출시 전에 확인해야 합니다.
