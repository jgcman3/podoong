# 작업 브랜치 검증 기록

확인일: 2026-10-29 · 브랜치: `feat/quick-care-experience`

## 통과한 검사

- `npm run typecheck`: 타입 검사 통과.
- `npm run lint`: 린트 통과.
- `npm test`: 21개 파일, 단위 테스트 102개 통과.
- `npm run db:test`: DB 테스트 538개와 먹이기 정리 검사 10개 통과. 로컬 DB만 사용.
- 비밀키 검사: 변경 파일에서 현재 앱 인증 키와 비밀키 패턴이 발견되지 않음. `.env.local`, Supabase 연결 캐시와 이전 백업은 Git에서 제외.

DB 검사에서 회원용 `growth_diary_feed` 함수가 재생성되며 기본 익명 실행 권한을 상속한 점을 발견했다. 후속 마이그레이션 `052`로 익명 실행을 제한하고 권한 회귀 검사를 추가했다. 공개 공유 링크 RPC는 변경하지 않았다. `052`는 로컬에만 적용했으며 원격 DB에는 아직 배포하지 않았다.

## 브라우저 검사 범위와 미해결 항목

전체 60개 검사는 5개 실패·2개 통과 후 중단했다. 진행 중이던 1개는 중단됐고 52개는 실행하지 않았다. 아래 실패들을 해결했다고 간주하지 않는다.

- 해외 국가만 선택한 뒤 저장하던 거주지 테스트: 현재 해외 지역 입력 요구와 기대 동작이 다르다.
- 일정 삭제 테스트: 삭제 후 목록 항목이 남는 실패를 확인했다. 원인 진단과 재현 확인이 필요하다.
- 예방접종 테스트: 제거된 `/services/vaccination` 경로를 사용한다. 현재 경로는 `/vaccinations`다.
- 가족 계정 테스트: 이전 `/settings` 링크를 기대한다. 현재 계정 메뉴 경로는 `/account`다.
- 반응형 메뉴 테스트: 이전 메뉴 개수·문구를 기대한다. 현재 성장 일기·동네 생활·아이 계정 구성을 반영해야 한다.

그 뒤 최근 기능 17개를 별도로 실행했다. 초기 결과는 12개 통과·4개 실패·1개 건너뜀이었다. 설정 메뉴 기대값에 개발자 요청 항목을 추가하고, 날짜와 생후 일수의 세로 중앙 정렬을 검사하며, 자정을 넘긴 단일 어린이집 기록이 두 날짜에 보이는 경우를 테스트 선택자에 반영했다. 수정한 4개를 다시 실행해 모두 통과했다. 두 실행을 합쳐 최근 기능 16개 통과·1개 건너뜀을 확인했으며, 전체 60개 통과로 보고하지 않는다.

브라우저 검사의 서버 로그에 `Permissions unavailable`도 출력됐다. 해당 테스트들의 assertion은 통과했지만, 후속 요청과 테스트 자료 정리 시점의 관계 등 원인은 추가 확인 대상이다.

건너뛴 라우터 캐시 재사용 검사는 프로덕션 실행 전용이다. 개발 서버 검사만으로 실제 운영 화면 전환 속도를 검증했다고 보고하지 않는다. 서울 프로젝트에서 실제 사용자의 카카오 재로그인 완료는 별도 확인이 필요하다.

## 선물·용돈 및 다크 모드 추가 검증

선물·용돈의 필수 입력, 금액 정밀도, 가족 접근 권한과 변경 충돌 검사를 추가했다. 최종 타입 검사·린트·단위 테스트 104개와 DB 검사 554개·기존 정리 검사 10개가 통과했다. 선물·용돈 전용 DB 검사 16개에는 다른 아이의 기록 ID 재사용 거절도 포함한다. 등록·수정·한국어/영어 받은 목록·20개 단위 추가 조회 및 동일 시각 기록의 중복/누락 방지를 브라우저로 확인했다.

밝게·어둡게·기기 설정의 전환, 새로고침 유지 및 주요 메뉴·입력창의 모바일/PC 표시를 검증했다. 후속 다중 화면 브라우저 실행은 긴 시스템 시간 경과로 시간 제한이 발생했으며, 별도 재실행에서 통과했다. 화면별 비교는 사진 자체를 변색시키지 않는 방식으로 진행했다.

서울 프로젝트에는 마이그레이션 `052`와 `053` 적용을 완료했다. 신규 필드 조회와 익명 저장 RPC 차단도 원격에서 확인했다. 외부 Claude 코드 검토 전송은 자동 승인 검토가 거절했으며, 코드는 전송되지 않았고 내부 검토를 사용했다.

최종 `ce-code-review` 내부 검토 완료: 보류된 결함 없음. 검토에서 발견한 큰 금액의 소수점 검증 문제는 회귀 검사를 추가하고 수정했다. 검토 기록은 로컬 임시 경로 `ce-code-review/20261029-received-J3eR4DYI`에 보관한다.

## 준 사람별 받은 내역·선물 사진·서비스 문서 (2026-10-29)

용돈 전체 합계·준 사람별 합계는 통화별로 구분하고 PostgreSQL numeric 집계를 문자열로 표시한다. 선물은 준 사람별 20개 단위 지연 조회로 구성했다. 선물 사진은 한 장의 비공개 Storage 파일과 표시용 WebP로 저장하고, 기록 저장·사진 교체/제거 메타데이터를 같은 RPC 트랜잭션으로 처리한다. 파일 없는 폼 전송 시 브라우저가 생성하는 빈 File을 제외해 사진 미첨부·제거 저장의 실패를 수정했다.

단위 검사 106개, DB 검사 576개와 기존 정리 검사 10개가 통과했다. 브라우저 3개로 선물/용돈 등록·수정, 준 사람별 추가 조회, 사진 미리보기·저장·교체·제거/취소, 비로그인 사진 접근 차단, 약관 열람·돌아가기를 확인했다. 추가로 PC·Safari 모바일 설정 및 일반 보호자 설정 화면 검사 2개도 통과해 이번 범위의 브라우저 검사 총 5개가 통과했다. 타입 검사와 린트도 통과했다. 문서는 `docs/legal` 초안을 그대로 표시하며 확정 시행이나 동의 수집을 구현한 것으로 간주하지 않는다.

서울 `atdyjsxfxlhwxmxgtnte`에 `054`를 적용했고 새 집계 RPC 두 개의 익명 호출이 401로 차단됨을 확인했다. 시드니 프로젝트는 변경하지 않았다.

## 수면 편집·식사 웹 푸시·놀이 타이머 (2026-10-29)

수면 편집에서 180분까지만 선택할 수 있던 원인은 소요시간 프리셋만 제공하고 종료 시각 입력이 없었던 UI였다. 브라우저 재현 검사에서 편집 입력 부재를 확인한 뒤 종료 시각 입력과 잠잔 시간 자동 계산으로 변경했다. 10시간 15분 저장·재편집, 자정 이후 종료, 빈 시각 입력을 확인한다. 수면은 초·소수 분을 표시하지 않는다. 기존 미커밋 작업과 겹치므로 자동 정리·커밋 없이 해당 변경을 직접 검토했다.

식사 알림은 단일 웹 푸시 채널로 구현했다. 설정 UI 검사는 OS 권한·푸시 공급자를 테스트 대역으로 분리하며 실제 기기 수신 검사로 간주하지 않는다. 로컬 실제 Edge Runtime에서 올바른 토큰의 빈 작업 200과 누락/잘못된 토큰 401을 확인했다. 운영에서는 DB 마이그레이션 055, Edge Function, VAPID 비밀 설정, Vault 인증과 Cron 연결을 완료했다. 운영의 실제 발송 테스트 요청은 실제 사용자에게 알림이 갈 수 있다는 이유로 자동 승인 검토에서 거절되어 실행하지 않았다. 이후 운영 검사는 구성·예약 활성 상태 조회만 수행했다. LAN HTTP 아이폰에서 수신 가능하다고 보고하지 않는다.

놀이·터미타임은 명시적 `timer_started`로 기존 수동 기록과 구분한다. 마이그레이션 056을 서울에 적용했다. 관련 DB 검사 11개, 식사 푸시 DB 검사 30개를 포함해 전체 617개와 기존 정리 검사 10개가 통과했다. 관련 브라우저 4개(긴 수면 편집, 식사 알림 켜기/끄기·설정, HTTPS/iPhone 설치 조건, 놀이/터미타임 시작·재접속·종료)가 함께 통과했다. 기존 수동 놀이 기록의 데이터가 그대로 유지됨도 확인했다.

타입 검사·린트와 단위 검사 129개가 통과했다. 일부 브라우저 검사 종료 시 개발 서버에 기존 `Permissions unavailable` 및 응답 스트림 종료 로그가 출력되었으며, 테스트 assertion 통과와 별도로 잔여 확인 대상으로 유지한다.
