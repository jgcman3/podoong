세 주소는 **Cloudflare Email Routing으로 운영자 개인 Gmail 한 개에 전달**합니다. 서로 다른 유료 메일 계정 세 개나 Google Workspace 구독은 필요하지 않습니다. 전달 수신과 도메인 주소 발신은 별개입니다. Gmail에서 그대로 답장하면 개인 Gmail 주소가 상대에게 보일 수 있으므로 도메인 발신이 필요한 답변은 인증된 발신 경로를 사용합니다. 고객 문서에는 개인 Gmail을 예비 연락처로 싣지 않습니다.

세 주소의 Gmail 전달 수신은 운영자가 2026-11-03 완료했다고 확인했습니다. 가입 확인 메일은 발송하지 않으므로 별도 발송 업체나 서버 키는 필요하지 않습니다.

## 운영 기준

현재 광고·마케팅·외부 분석 SDK·건강정보 판매·AI 학습은 하지 않습니다. 자체 익명 일별 화면 집계만 90일 보유합니다. 추후 광고 전 개인사업자 등록과 실제 광고업체·쿠키·아동정보·동의 검토를 진행합니다. 가입 때의 선택 동의가 미래 광고 동의가 되지 않습니다.

기본 DB/Auth/Storage/백업은 Supabase 서울, 웹 계산은 Vercel 서울이며 글로벌 CDN·로그·지원·메일의 해외 처리는 별도로 안내합니다. 국내 리전 설정을 전 정보의 국내 잔류 보장으로 표현하지 않습니다. 건강정보는 가입 화면에서 별도 필수 항목으로, 일기 공개·공유와 놀이터는 각각 공개·참여를 선택할 때 받고 계정 설정에서 바꿉니다. 영어 UI 요약은 제공할 수 있지만 현재 완전한 법률 원문은 한국어입니다.

실제 운영 배포 전에 개발·운영 동의 스키마 적용과 원문 스냅샷, 선택 철회의 서버 차단·삭제, 정기 파기·파일 정리·백업 복원 절차를 확인합니다. 세부 확인표는 구현 명세를 사용합니다.
