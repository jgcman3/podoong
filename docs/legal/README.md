해외 서비스에서는 국가별 적용 요건을 구분한다. EU 대상 제공·관찰 등 GDPR 적용 조건을 확인하고, 성인 보호자가 아이 사진을 올리는 서비스라는 이유만으로 미국 COPPA가 자동 적용된다고 단정하지 않는다. [EDPB 적용 범위 지침](https://www.edpb.europa.eu/sites/default/files/files/file1/edpb_guidelines_3_2018_territorial_scope_after_public_consultation_en_1.pdf), [FTC COPPA FAQ](https://www.ftc.gov/business-guidance/resources/complying-coppa-frequently-asked-questions)를 기준으로 실제 이용자·수집 흐름을 검토한다.


## 가입 동의 구현 — 2026-10-30

개발 환경은 소셜 인증 → 문서별 가입 동의 → 보호자·아이 정보 입력 순서로 진행한다. 필수 항목은 이용약관과 가입 개인정보 수집·이용 두 가지이며 처리방침은 별도 안내 링크로 제공한다. 체크박스를 미리 선택하지 않고, 거부 시 로그아웃해 나갈 수 있다.

`signup_document_versions`에 개발 초안의 고정 전문과 SHA-256을, `signup_agreements`에 문서별 계정·버전·화면 언어·서버 동의 시각을 기록한다. 계정 삭제 시 증빙도 삭제 대상으로 연결한다. 기존 `consented_at`를 새 문서 동의로 소급하지 않는다. 상세 구현·검증 범위는 [가입 동의 흐름](../implementation/signup-agreements.md)을 참고한다.

**이는 개발용 초안의 확인 흐름이다.** 정식 약관 시행, 법정대리인 확인, 건강정보·공개/공유·국외 이전에 필요한 별도 근거가 모두 완료됐다는 의미가 아니다. 영문 화면에서도 현재 전문은 한국어 원문임을 표시한다.
