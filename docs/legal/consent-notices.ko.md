# 가입 동의 안내

버전 signup-2026-11-03-v1
시행일: 2026-11-03
수정일: 2026-11-05

가입 화면에서는 이용약관, 보호자·아이 기본 개인정보 수집·이용(권한 선언 포함), 별도 건강정보 처리 동의(가입 필수)의 세 항목만 받습니다. 필수 세 항목은 미리 체크하지 않으며, 모두 동의로 함께 선택하거나 각 항목을 개별 선택할 수 있습니다. 공개 일기·공유와 놀이터 참여는 해당 동작을 직접 선택할 때 안내하고 선택을 받습니다. 소셜 로그인 동의나 브라우저 알림 권한이 아래 선택을 대신하지 않습니다.

| 구분         | 선택 문구                                                                                                     | 거부 시 영향                            |
| ------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| 필수         | 서비스 이용약관에 동의합니다.                                                                                 | 가입 완료 불가                          |
| 필수         | 보호자·아이 기본 개인정보 수집·이용에 동의하며 적법한 아동 처리 권한을 선언합니다.                                                | 해당 기록 서비스 가입 완료 불가         |
| 필수         | 아이의 건강정보를 가족 돌봄·성장 분석을 위해 처리하는 데 동의합니다.                                          | 미동의 시 가입 완료 불가                |
| 공개 시      | 공개한 성장일기를 서비스 이용자와 로그인하지 않은 일기장 링크 방문자에게 제공하는 데 동의합니다.              | 비공개 보관 가능, 공개·공유 제한        |
| 최초 참여 시 | 아이의 동네 놀이터 프로필을 같은 동네 이용자에게 제공하는 데 동의합니다.                                      | 놀이터 참여 제한, 나머지 기능 이용 가능 |

각 항목의 목적·항목·기간·받는 사람·거부 권리는 [가입 수집·이용 안내](signup-privacy.ko.md) 및 [개인정보 처리방침](privacy-policy.ko.md)의 해당 표를 함께 제공합니다. 전체 동의가 있어도 선택별 결과를 따로 저장합니다. 건강·공개·놀이터 선택을 하나의 필수 처리로 묶지 않습니다.

가입 화면에서는 로그인한 성인 보호자의 법정대리인 또는 적법한 위임 권한 선언을 체크박스로 받습니다. 별도 이메일 확인은 요구하지 않습니다. 이는 혈연·친권·후견 관계를 공적으로 인증하는 절차가 아닙니다. 대리권 의심·분쟁이 있으면 해당 아이 처리를 제한하고 필요한 확인을 진행합니다.

이후 기능 화면에서는 같은 동의를 반복해서 묻지 않습니다. 일기 공개·공유와 놀이터 참여는 해당 동작을 직접 선택할 때 안내하고, 사용자는 일기 편집·공유 화면에서 공개 범위를 변경하고 동네 놀이터 화면에서 참여를 중단할 수 있습니다. 그 밖의 동의 철회·처리정지 요청은 privacy@podoong.com으로 받습니다. 공개 철회 시 이후 일기 공개·링크 제공을 중단하고 놀이터 철회 시 프로필 제공을 중단합니다. 건강 철회 시 관련 입력·분석을 중단하고 해당 목적의 건강정보 삭제를 처리합니다. 기존 공동 기록·첨부 이미지·이미 외부에 전달된 사본의 한계도 함께 안내합니다.

새로운 목적·민감정보·받는 사람 등 본질적 변경이 있는 경우 기존 가입 동의를 포괄적인 미래 동의로 사용하지 않고 필요한 안내·동의를 진행합니다. 법적 필수 절차가 바뀌는 경우까지 ‘다시는 동의를 받지 않는다’고 약속하지 않습니다.

가입 시 문서 원문과 버전·해시, 계정, 서버 동의 시각, 선택별 결과, 권한 선언을 기록합니다. 선택 변경 이력은 현재 상태와 구분하고 해당 계정·아이 삭제 시까지 보유합니다. 소셜 비밀번호·불필요한 신분증은 보관하지 않습니다. 문서의 자세한 화면·데이터 연결 기준은 [구현 명세](../implementation/privacy-consent.md)에 있습니다.
