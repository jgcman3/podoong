# 포둥 동의 안내와 화면 문안

버전 0.2 · 작성일 2026-10-29 · **검토용 초안 / 실제 동의 UI·증빙 구현 전**

## 확정한 화면 방향

베이비타임의 간결한 가입·입력 방식을 참고하되, 아래 상세 문안을 가입 화면에 한꺼번에 펼치지 않습니다. 짧은 문구와 전문 보기 링크를 사용하고, 같은 목적·같은 버전의 동의를 기록할 때마다 반복해서 요구하지 않습니다.

| 시점                             | 화면에 표시할 내용                                                      |
| -------------------------------- | ----------------------------------------------------------------------- |
| 가입                             | 이용약관 동의와 개인정보 안내. 별도 수집·이용 동의가 필요한 항목만 구분 |
| 아이 등록                        | 법정대리인 동의·확인 또는 적법한 위임 관계 확인                         |
| 건강정보 첫 이용                 | 해당 아이의 건강정보 처리에 대한 별도 동의                              |
| 공개·공유 첫 이용 또는 범위 변경 | 공개 대상과 항목을 짧게 안내하고 선택 확인. 공유 종료 기능 함께 제공    |

필수 확인·동의의 내부 증빙은 유지합니다. 경쟁사 공개 처리방침만으로 실제 앱의 확인 절차를 알 수 없으므로, 이를 법정대리인 확인이나 건강정보 동의를 생략하는 근거로 삼지 않습니다. 이번 결정은 문서와 구현 방향에 관한 것이며, 기존 사용자가 이미 동의한 것으로 소급 기록하지 않습니다.

## 1. 동의 설계 원칙

이용약관 동의, 처리방침 열람 안내, 동의를 근거로 한 수집·이용, 아동 법정대리인 확인, 민감정보 처리, 제3자 제공, 국외 이전을 한 체크박스에 묶지 않습니다. 처리방침 자체에 동의해야 모든 수집·제공이 허용된다고 안내하지 않습니다. 필수/선택은 계정 전체가 아니라 해당 목적과 기능에 필요한 범위로 정합니다. 동의 외 처리 근거를 사용하는 항목은 해당 근거를 확인한 뒤 중복·형식적 동의를 요구하지 않습니다.

다음은 화면에 사용할 문안 초안입니다. `[게시 전 확정]`이 있는 문안은 확정 전 수집에 사용할 수 없습니다. 선택 항목을 미리 체크하거나 약관 미동의를 다른 선택 항목까지 자동 동의한 것으로 처리하지 않습니다.

## 2. 가입 화면

### 이용약관

`[필수] 포둥 서비스 이용약관에 동의합니다. [전문 보기]`

개인 운영자, 무료 서비스 범위, 가족관리자 권한, 탈퇴 시 아이 전체 삭제, 일기 공개·링크 공유 등 중요한 조건을 열람할 수 있게 합니다.

### 개인정보 안내

`개인정보를 어떻게 처리하는지 확인해 주세요. [개인정보 처리방침]`

동의를 근거로 가입 정보를 처리할 항목이 있다면 아래 표를 먼저 제공하고 별도 선택을 받습니다. 계약 이행 등 다른 근거를 적용할 항목과 혼동하지 않도록 최종 처리 근거를 확정합니다.

| 목적                     | 항목                                                                                                 | 보유기간                                                         | 거부 시 영향                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| 회원 가입·식별·가족 연결 | 실제 수신하는 소셜 식별자·기본 프로필, 내부 계정 ID, 보호자 표시 이름, 아이와의 관계, 가족 연결·권한 | 계정 탈퇴·목적 달성 시까지. 동의 증빙 별도 기간은 [게시 전 확정] | 해당 동의가 필수 처리 근거인 경우 가입·가족 연결을 제공할 수 없음 |

`[필수: 동의 근거 적용 항목에 한함] 위 개인정보 수집·이용에 동의합니다.`

이메일은 제공된 경우 처리하며 소셜 계정에서 받지 않는 이메일을 필수라고 안내하지 않습니다. 단순 가입에 아이 건강정보·사진 공개 동의를 강제하지 않습니다.

## 3. 아이 등록과 법정대리인 확인

`등록하는 아이의 개인정보를 처리할 권한을 확인해 주세요.`

- 처리 목적: 아이 등록, 가족 돌봄 및 생후 일수·기록 관리.
- 기본 항목: 아이 이름 또는 닉네임, 태어난 날, 성별, 가족 연결 정보.
- 보유기간: 아이 정보 삭제 또는 해당 처리 근거 소멸 시까지. 동의·대리권 증빙 보유기간은 [게시 전 확정].
- 거부 권리: 아이 기본 정보 처리에 동의하지 않을 수 있으며, 동의를 근거로 하는 해당 아이 등록·기록 기능은 제공할 수 없습니다.

`[해당 아이 등록에 필요] 저는 이 아이의 법정대리인이며 위 개인정보 처리에 동의합니다.`

법정대리인이 아닌 보호자는 단순히 위 문구에 체크할 수 없습니다. 법정대리인의 확인된 동의와 적법한 위임 범위를 연결하는 별도 절차를 제공합니다. **확인 방법·확인 주체·최소 증빙·보유기간은 게시 전 확정 및 구현 대상**입니다. ‘엄마·아빠’ 선택이나 초대 수락만으로 이 절차를 대신하지 않습니다.

## 4. 건강정보 처리

건강 기록을 시작할 때 아동별 동의 범위를 안내하고 법정대리인의 별도 동의 등 적법한 근거를 마련합니다.

| 목적                                                           | 항목                                                                                                                 | 보유기간                                                                                                            | 거부 시 영향                                                                                              |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 아이 건강·성장 기록, 가족 공동 돌봄, 사용자가 요청한 분석·알림 | 체온, 투약, 병원 방문, 예방접종/독감, 건강정보에 해당하는 키·몸무게·머리둘레·발달 관찰, 이용자가 적은 건강 관련 메모 | 해당 기록 삭제, 아이 삭제 또는 해당 동의 철회에 따른 처리 종료 시까지. 법적 예외·백업 기간은 확정된 처리방침에 따름 | 건강정보 기능만 제한. 동의하지 않았다는 이유로 건강정보 처리가 필요 없는 기본 기능까지 일괄 제한하지 않음 |

`[건강정보 기능 이용 시 별도] 이 아이의 건강정보 처리에 동의합니다.`

가족 보호자에게 건강정보를 보여주는 행위에 제3자 제공 등 별도 근거가 필요한지도 함께 검토합니다. 건강정보를 외부 공개·광고·AI 학습하는 동의는 이 문안에 포함되지 않습니다.

## 5. 일기 공개와 공유 링크

### 공개 일기

`이 일기를 공개하면 아이 이름/닉네임·성별·생후 일수·글·사진이 공개 목록 이용자에게 보입니다. 출생일별 탭에는 입력한 성장 수치도 보일 수 있습니다. 날짜와 생후 일수를 통해 생일이 추정될 수 있어요.`

`[선택] 이 일기를 선택한 공개 범위로 제공하는 데 동의합니다.`

공개받는 사람: 선택한 출생일별/전체 공개 목록에 접근하는 서비스 이용자. 목적: 공개 성장일기의 열람·소통. 항목: 실제 공개되는 이름/닉네임·성별·생후 일수·본문·사진·선택한 성장 수치. 제공 기간: 해당 공개를 종료하거나 일기를 삭제할 때까지. 거부 시 가족 내부의 비공개 보관은 이용할 수 있습니다. 성장·건강 정보 공개가 포함되면 민감정보 처리/제공에 필요한 동의를 추가 구분합니다.

현재 기본 공개·비공개 체크만 있는 UI는 위의 명확한 선택·동의 흐름과 일치하도록 게시 전 보완해야 합니다.

### 아이별 링크 공유

`링크를 가진 사람은 로그인 없이 이 아이의 공개 일기와 사진을 볼 수 있어요. 앞으로 공개하는 일기도 같은 링크에 표시돼요. 이미 전달된 사본은 회수할 수 없어요.`

`[선택] 링크 소지자에게 이 아이의 공개 일기를 제공하는 데 동의합니다.`

제공받는 사람: 링크를 전달받거나 확보한 누구나. 목적: 이용자가 선택한 아이 일기장 공유. 항목: 아이 이름/닉네임, 일기 날짜·본문·사진 및 사진 속 정보. 기간: 공유 링크 종료·일기 비공개 전환·삭제 등 제공 종료까지. 거부하면 링크 공유만 이용할 수 없으며 가족 내부 보관에는 영향이 없습니다. 세부 수령자 특정이 어려운 링크 제공의 동의 방식은 공개 전 법률 검토로 확정합니다.

링크 만들기·새 링크 발급·끄기 화면에서 해당 아이와 공개 범위를 다시 확인합니다. 링크 복사만으로 다른 목적의 이용까지 허용한 것으로 보지 않습니다.

## 6. 해외 지역 명칭 등록

`입력한 시도·도시·동네 이름은 다른 가족도 주소 선택에 사용할 수 있어요. 집 번지·동호수·전화번호·사람 이름은 입력하지 마세요.`

공용 목록에는 행정구역 명칭만 제공하고 가족·아이·등록자 정보는 제공하지 않습니다. 가족의 주소 설정·지역 그룹 참여라는 개인정보 처리와 지역 명칭 목록이라는 공용 자료를 구분합니다.

## 8. 개발자에게 요청하기

화면 안내: `기능 제안이나 오류를 알려주세요. 아이의 개인정보·건강정보는 적지 마세요.`

구분·요청 본문·접수 시각·작성 계정을 문의 처리 목적으로 저장합니다. 계정 삭제 시 앱 내 요청도 삭제 대상으로 연결합니다. 처리 완료 후 최대 보관기간 및 담당자의 확인 절차는 게시 전 확정합니다. 이메일 회신이 필요하면 수신 이메일을 별도 확인하며 소셜 계정에 이메일이 없는 이용자에게 회신을 보장하지 않습니다.

## 9. 동의 증빙과 철회 구현

문서별 식별자·버전·전문 해시/고정 사본, 동의 주체·대상 아이, 처리 목적·공개 범위, 선택 결과·시각, 대리권 확인 방법과 최소 확인 결과, 철회 시각·적용 범위를 구분해 기록합니다. IP·기기정보는 증빙이라는 이유만으로 무조건 추가 수집하지 않습니다.

중요 항목을 변경하면 필요한 범위에서 다시 동의받고, 과거 동의를 새 목적의 동의로 소급하지 않습니다. 현재 일반 가입 동의 시각 하나만으로 위 전부를 구현했다고 간주할 수 없습니다.
